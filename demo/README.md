# demo

Собственные before/after планы, рекомендация, описание эффекта и инструкция ZIP.

**Владелец:** поток 5. **Пакеты:** E01.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Планы создаются в редакторе на синтетических данных. example_plan.json из корня — тестовый ориентир, не результат команды.
