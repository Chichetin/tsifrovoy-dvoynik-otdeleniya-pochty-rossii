# Цифровой двойник отделения Почты России

Проект команды из пяти разработчиков для хакатона Почтатеха: редактор синтетического
плана отделения, инвентаризация, проверки, объяснимые рекомендации и условный 3D-вид.

**Текущее состояние:** архитектура, план и каталоги модулей подготовлены. Реализация
приложения ещё не начата; команд запуска и работающего демо пока нет. Первые задачи —
F01 (запускаемый каркас) и F02 (контракты и тестовые данные).

## Начать работу

1. Прочитать [CLAUDE.md](CLAUDE.md), [правила Git](GIT.md) и [HANDOFF](HANDOFF.md).
2. Найти свой модуль в [карте каталогов и владельцев](docs/project-structure.md).
3. Взять пакет из [плана 34 задач для пяти потоков](docs/plans/2026-09-16-parallel-plan.md)
   и работать в личном worktree.

Данные только синтетические. В продукте LLM — Qwen/DeepSeek по API, ключи только
на сервере. Геометрию и числа считает код; инвентаризация, 3D и рекомендации используют
одну модель плана. Новые типы оборудования добавляются через данные справочника.

Предлагаемый стек и порядок его фиксации описаны в архитектуре. После F01 здесь
появятся проверенные команды установки, запуска и тестов; после деплоя — адрес сервиса
и сценарий «открыть → загрузить демо → изменить → сохранить → открыть заново».
