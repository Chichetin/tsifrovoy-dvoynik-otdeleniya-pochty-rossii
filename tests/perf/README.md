# tests/perf

Повторяемые замеры открытия, отклика, проверки и нагрузки на планах фиксированного seed.

**Владелец:** поток 5.

## Граница модуля

Это измерения с сырыми результатами, а не оценка на глаз. Итоговые числа — в `README.md`.

## Запуск

- `npm run test:perf` — dev-сервер, числа публикуются, пороги не проверяются.
- `PERF_SERVER=preview npm run test:perf` — конфиг собирает `vite build` и поднимает
  `vite preview`: production-сборка, как на публичном сервисе. Здесь спека проверяет медианы
  на каждом объёме: выбор из перечня < 400 мс, шаг zoom < 300 мс (D-187). Валидация на этой
  сборке не меряется — её модуль не импортируется из `dist`.

Сырые значения каждого объёма — `test-results/…/samples.json` (коммит, сервер, машина,
load average на конец прогона).

## Файлы

- `editor.spec.ts` — замер на 100, 500 и 1000 объектах (`scripts/generate-benchmark.ts`).
