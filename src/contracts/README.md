# src/contracts

Общие типы, схемы входных данных, команды, UI-протокол и словарь фактов/объяснений.

**Владелец:** поток 1. **Пакеты:** F02.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Никаких импортов реализации из domain, state, features, persistence или server. React-типы разрешены только в ui.ts; server/domain не импортируют ui.ts.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `model.ts` — F02.
- `commands.ts` — F02.
- `advice.ts` — F02.
- `advice-semantics.ts` — F02.
- `ui.ts` — F02.
- `schema.ts` — F02.
