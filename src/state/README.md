# src/state

Единый документ, revision, selection, dirty, baseline экспорта, undo/redo.

**Владелец:** поток 1. **Пакеты:** S01 — реализован.

`createPlanStore(document)` возвращает zustand-store с поверхностью `PlanStore` из
контрактов: `document`, `revision`, `selection`, `dirty`, `retired` только для чтения,
правки — через `dispatch`. История и baseline экспорта лежат в замыкании, поэтому наружу
не протекают; набор удалённых id (`retired`) отдаётся копией при каждом коммите — по нему
инструменты рисования и установки выбирают свободный id, иначе «удалить → поставить снова»
упиралось в отказ `ID_REUSED` (D-156). UI подписывается через `useStore` из zustand;
синглтона нет — store создаёт `src/app`.

`replaceDocument` молча заменяет документ и очищает историю: подтверждение при
`dirty = true` — обязанность вызывающего (файловый UI, IO03), store только сообщает
`dirty`. Наблюдаемых `canUndo`/`canRedo` в контракте v1 нет; если они понадобятся
тулбару, это правка контракта отдельным MR, а не тихое расширение поверхности.

## Граница модуля

Потребляет contracts и domain/commands. Не импортирует UI, server и persistence; загрузку подключает app.
