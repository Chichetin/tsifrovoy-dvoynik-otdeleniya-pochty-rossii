# src/state

Единый документ, revision, selection, dirty, baseline экспорта/сравнения, undo/redo.

**Владелец:** поток 1. **Пакеты:** S01 — реализован.

`createPlanStore(document)` возвращает zustand-store с поверхностью `PlanStore` из
контрактов: `document`, `baseline`, `revision`, `contentRevision`, `selection`, `selected`, `dirty`, `retired` только для
чтения, правки — через `dispatch`. История и признак состоявшегося экспорта лежат в
замыкании. `baseline` доступен только для чтения, чтобы ассистент считал «было → стало»
от того же снимка, относительно которого store определяет `dirty`. Видимость слоёв (`layers[].visible`) в `dirty` не участвует: показ слоя — не правка (D-207), хотя в файл флаг попадает. Набор удалённых id
(`retired`) отдаётся копией при каждом коммите — по нему
инструменты рисования и установки выбирают свободный id, иначе «удалить → поставить снова»
упиралось в отказ `ID_REUSED` (D-156). UI подписывается через `useStore` из zustand;
синглтона нет — store создаёт `src/app`.

`revision` растёт при каждом успешном шаге истории; `contentRevision` для актуальности ответа ассистента не меняется от одного лишь показа слоя и его undo/redo, но растёт при правке содержимого и замене плана (D-317).

Групповой выбор (D-184): `selected` — объекты, выбранные рамкой или Shift+кликом,
`selection` — главный из них; `select(ref)` — группа из одного, `selectMany(ids)` —
группа с главным-последним. Оба поля чистятся вместе с документом на каждом коммите, и
нетронутая группа остаётся той же ссылкой (D-177). Пакет команд `batch` — один шаг
истории и один набор `retired`; отказ шага не оставляет следа.

`replaceDocument` молча заменяет документ и очищает историю: подтверждение при
`dirty = true` — обязанность вызывающего (файловый UI, IO03), store только сообщает
`dirty`. Наблюдаемых `canUndo`/`canRedo` в контракте v1 нет; если они понадобятся
тулбару, это правка контракта отдельным MR, а не тихое расширение поверхности.

## Граница модуля

Потребляет contracts и domain/commands. Не импортирует UI, server и persistence; загрузку подключает app.
