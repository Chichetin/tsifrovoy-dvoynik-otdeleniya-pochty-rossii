# src/app

Сборка приложения: подключение модулей, маршрутизация команд и событий инструментов, глобальные стили.

**Владелец:** поток 2. **Пакеты:** U01, UI-2Б.
Реализовано пакетом U01: `App.tsx` — единственное место сборки редактора, хранит сессию (инструмент, вид, выделение) и маршрутизирует команды в единый store; `styles.css` — общий вид панелей; `default-plan.ts` — справочник из `data/catalog` и пустой план для «Нового».
Боковые колонки — вкладки (D-247, заменило сворачиваемые разделы UI-2Б/D-236): `SideTabs.tsx` — ряд вкладок WAI-ARIA и панели, скрытые панели остаются в DOM (`hidden`); `side-tabs.ts` — чистая логика без DOM (список вкладок, вкладка по умолчанию, чтение/запись `localStorage` под ключом `ops-twin.side-tabs.v1`, переход по стрелкам/Home/End).

## Граница модуля

Единственная точка соединения store и UI-модулей. Геометрия и расчёт рекомендаций не живут в App.tsx. `SideTabs`/`side-tabs.ts` не знают о конкретных панелях — только оборачивают их снаружи, панели передаёт `App.tsx`.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `App.tsx` — U01.
- `styles.css` — U01.
- `connect-panels.tsx` — U01.
- `SideTabs.tsx`, `side-tabs.ts` — D-247: вкладки обеих боковых колонок. «Свойства» не вкладка: без выбора карточки нет, при выборе она над вкладками правой колонки с кнопкой «×» «Снять выделение».
- `hotkeys-map.ts`, `HotkeysMapDialog.tsx` — пакет №3 очереди UX (D-243): единый список `HOTKEYS_MAP` всех горячих клавиш редактора и накладка по `?`. Файл лежит здесь, а не в `features/editor` или `features/equipment`, потому что сводит хоткеи обеих features, а граница импортов не даёт одной feature читать файлы другой. Открытие/закрытие, возврат фокуса и слушатель `?`/`Escape` — в хуке `useHotkeysMapDialog`; кнопка вызова — в левой панели рядом с «Обучение».
