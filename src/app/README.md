# src/app

Сборка приложения: подключение модулей, маршрутизация команд и событий инструментов, глобальные стили.

**Владелец:** поток 2. **Пакеты:** U01, UI-2Б.
Реализовано пакетом U01: `App.tsx` — единственное место сборки редактора, хранит сессию (инструмент, вид, выделение) и маршрутизирует команды в единый store; `styles.css` — общий вид панелей; `default-plan.ts` — справочник из `data/catalog` и пустой план для «Нового».
Пакетом UI-2Б (D-217) добавлены `Section.tsx` — обёртка правой колонки: заголовок-кнопка со сводкой, липкая при прокрутке, содержимое остаётся в DOM (`hidden`, не размонтирование); `right-column.ts` — чистая логика без DOM (какие разделы свёрнуты, чтение/запись `localStorage` под ключом `ops-twin.right-column.v1`, русское склонение счётчика), тем же приёмом, что и `features/onboarding/tour.ts`.

## Граница модуля

Единственная точка соединения store и UI-модулей. Геометрия и расчёт рекомендаций не живут в App.tsx. `Section`/`right-column.ts` не знают о конкретных панелях — только оборачивают их снаружи по `id`/заголовку/сводке, которые передаёт `App.tsx`.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `App.tsx` — U01.
- `styles.css` — U01.
- `connect-panels.tsx` — U01.
- `Section.tsx`, `right-column.ts` — UI-2Б: сворачиваемые разделы правой колонки. Сама колонка подстраивается под выбор (D-236): есть выбор — «Свойства» раскрыты, остальные разделы свёрнуты в заголовки; выбора нет — свёрнуты «Свойства». Это вывод из выбора, а не состояние: `collapsedOf` в `App.tsx` считает его на лету, в `localStorage` он не пишется и сохранённую раскладку не затирает. Щелчок по заголовку сильнее автоматики и держится до смены выбора (`manualSections`) — заглянуть в «Площади», не бросая выбранный объект, можно одним щелчком.
- `hotkeys-map.ts`, `HotkeysMapDialog.tsx` — пакет №3 очереди UX (D-243): единый список `HOTKEYS_MAP` всех горячих клавиш редактора и накладка по `?`. Файл лежит здесь, а не в `features/editor` или `features/equipment`, потому что сводит хоткеи обеих features, а граница импортов не даёт одной feature читать файлы другой. Открытие/закрытие, возврат фокуса и слушатель `?`/`Escape` — в хуке `useHotkeysMapDialog`; кнопка вызова — в левой панели рядом с «Обучение».
