# src/app

Сборка приложения: подключение модулей, маршрутизация команд и событий инструментов, глобальные стили.

**Владелец:** поток 2. **Пакеты:** U01.
Реализовано пакетом U01: `App.tsx` — единственное место сборки редактора, хранит сессию (инструмент, вид, выделение) и маршрутизирует команды в единый store; `styles.css` — общий вид панелей; `default-plan.ts` — справочник из `data/catalog` и пустой план для «Нового».

## Граница модуля

Единственная точка соединения store и UI-модулей. Геометрия и расчёт рекомендаций не живут в App.tsx.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `App.tsx` — U01.
- `styles.css` — U01.
- `connect-panels.tsx` — U01.
