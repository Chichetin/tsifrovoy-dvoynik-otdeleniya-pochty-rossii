# src/domain/advice

Поиск размещений, комплектование, сравнение планов, проверка объяснений и шаблоны.

**Владелец:** поток 4. **Пакеты:** A01 A02 A03 A04.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts и публичные функции geometry/relations/metrics/catalog/inventory. Никаких API-ключей или вызовов LLM.

**Уместность зоны (D-186).** `zoneFit` в `placement.ts`: уместные типы зон — из правил
комплектования `count` с заданным `min` (в том числе `0`) **и** из текущей расстановки
(где объекты этого типа уже стоят). Сужается только тип с правилом-минимумом; правило
только с `max` — потолок, а не «дом»; объекты с `occupiesFloor: false` не сужаются.
Сверяется собственная (самая глубокая) зона места. Нет правила — ищем везде и говорим
об этом; нет зон в плане — уместность не проверяется; явно выбранная неподходящая зона —
выбор человека с пометкой; уместной зоны нет — пустой ответ с объяснением. Зоны вариантов
попадают в `refs` рекомендации.
