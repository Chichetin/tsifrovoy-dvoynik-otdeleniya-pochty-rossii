# src/domain

Чистые функции предметной области, одинаковые для браузера и сервера.

**Владелец:** поток 1. **Пакеты:** G01 G02 G03 S01 V01 C01 M01 A01 A02 A03 A04.

## Граница модуля

Без React, DOM, store, файловой системы, сети, env и текущего времени. Владельцы дочерних модулей указаны отдельно.

`content-layer.ts` задаёт единое правило слоя для содержимого: зоны и оборудование можно
добавлять или переносить только в обычный (`typeId: null`) незапертый слой (D-174).

`physics/` — набор из пяти правил физики плана и два его применения (D-286):
`objectPhysicsIssues` считает нарушения одного объекта против всего плана (этим
живёт граница жеста), `physicsIssues` отбирает физику из находок `validatePlan`
(этим живёт запрет сохранения), `physicsRejection` отвечает «так править нельзя»,
сравнивая нарушение по коду и участникам — уже нарушающий объект остаётся
передвигаемым. Коды и сообщения общие с `validation`, список для человека —
`PHYSICS_RULES`. `editRejection` — единый допуск команды для store, включая шаги
`batch`: объекты — `physicsRejection`, проёмы — `opening.ts` (`openingRejection`,
`openingDeleteRejection`; превью инструмента «Проём» вызывает ту же функцию, D-359).

`object-mount.ts` — напольный или потолочный объект по его `base_m` (порог `CEILING_BASE_M` = 2,0 м, правило команды, D-275) и вид документа для холста/3D, где скрытая группа лежит на скрытом служебном слое (`withHiddenMounts`).

`plan-index.ts` — единственный ответ на «как называется этот id»: `planIndex(plan)` строит
словари один раз, `nameOf(ref)`, `objectLabel`, `zoneName`, `layerName`, `objectTypeLabel`,
`zoneTypeLabel` отвечают за O(1) и одинаково — `null`, когда сущности нет (D-202).

`number-format.ts` — запись чисел для человека: запятая, разряды и единица через
неразрывный пробел (`formatArea`, `formatLength`, `formatMeasure`, `formatShort`). Её
используют панели features; файлы, CSV, SVG-экспорт и тексты `advice`/`validation`
своих форматов не меняют (D-197).

`heat-color.ts` — цвет значения на шкале слоя `zone-heat` (`heatColor`). Один на холст 2D и пол 3D,
чтобы число давало один цвет в обоих видах.
