# src/domain/inventory

Перечень объектов и подсчёт по типам/зонам, direct/inclusive, неназначенные объекты.

**Владелец:** поток 3. **Пакеты:** M01.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts. Производные данные вычисляются из документа, собственная изменяемая копия плана не создаётся.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `index.ts` — M01.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
