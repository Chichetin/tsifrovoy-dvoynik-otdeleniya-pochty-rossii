# src/domain/inventory

Перечень объектов и подсчёт по типам/зонам, direct/inclusive, неназначенные объекты.

Обход (`walk.ts`, #124): `walkRoute` строит маршрут от главного входа через каждый объект один раз — ближайший сосед, затем 2-opt; расстояние — прямая между центрами, стены не учитываются. Отметка обхода — атрибуты объекта `inventoryCheck` (`present` / `missing` / `other-number` / `broken`) и `inventoryFoundNumber`; они сохраняются в файл плана без правки формата.

**Владелец:** поток 3. **Пакеты:** M01.

## Граница модуля

Потребляет contracts. Производные данные вычисляются из документа, собственная изменяемая копия плана не создаётся.
