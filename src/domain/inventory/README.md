# src/domain/inventory

Перечень объектов и подсчёт по типам/зонам, direct/inclusive, неназначенные объекты.

**Владелец:** поток 3. **Пакеты:** M01.
Реализовано пакетом M01: `buildInventory(plan)` — производный расчёт без собственного состояния. `byZoneInclusive` поднимает объект ко всем предкам зоны, поэтому суммировать можно только `byZoneDirect` вместе с `unassigned` (D-028); пустые типы и зоны показываются нулями (D-029).

## Граница модуля

Потребляет contracts. Производные данные вычисляются из документа, собственная изменяемая копия плана не создаётся.

- `index.ts` — M01.
