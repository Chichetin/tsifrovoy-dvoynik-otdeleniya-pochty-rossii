# src/domain/inventory

Перечень объектов и подсчёт по типам/зонам, direct/inclusive, неназначенные объекты.

`inventoryObjectLink` строит ссылку с id плана и предмета, без пароля и посторонних параметров исходного адреса. `inventoryLinkTarget` читает её параметры; `resolveInventoryLink` выбирает предмет только в нужном плане. Если файл другой или предмет удалён, функция сообщает это вызывающему UI.

Обход (`walk.ts`, #124): `walkRoute` строит маршрут от главного входа через каждый объект один раз — ближайший сосед, затем 2-opt с бюджетом 150 мс; расстояние — прямая между центрами, стены не учитываются. Отметка обхода — атрибуты объекта `inventoryCheck` (`present` / `missing` / `other-number` / `broken`) и `inventoryFoundNumber`; они сохраняются в файл плана без правки формата. `reconcileRoute` вставляет новый объект в маршрут и убирает удалённый. `walkActEntries` отбирает строки акта: всё, что не «на месте».

**Владелец:** поток 3. **Пакеты:** M01.

## Граница модуля

Потребляет contracts. Производные данные вычисляются из документа, собственная изменяемая копия плана не создаётся.
