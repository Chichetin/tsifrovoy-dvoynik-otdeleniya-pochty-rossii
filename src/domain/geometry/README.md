# src/domain/geometry

Полигоны, повёрнутые footprints, пересечения, преобразование координат, стены и проёмы.

**Владелец:** поток 1. **Пакеты:** G01.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts и математические библиотеки. Не знает о зонах как бизнес-сущностях, UI или API.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `index.ts` — G01.
- `polygons.ts` — G01.
- `coordinates.ts` — G01.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
