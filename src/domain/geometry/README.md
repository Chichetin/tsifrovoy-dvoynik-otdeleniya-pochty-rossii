# src/domain/geometry

Полигоны, повёрнутые footprints, пересечения, преобразование координат, стены и проёмы.

`footprint(object)` (D-277) — контур объекта (`outline` в долях `size_m`, без него — прямоугольник), растянутый размером, повёрнутый и поставленный в мир. Форму типа загрузка и команды уже записали в объект, поэтому геометрия справочника не знает; `symbolOutline`/`typeOutline`/`withTypeOutline` реэкспортируются из `contracts/outline.ts`.

Перетаскивание объекта (#20): `objectGuides` — края и центры рамок соседей, грани стен; `dragObstacles` один раз на жест готовит контуры стен и соседей, `objectGaps` на каждом шаге даёт кратчайший зазор до ближайшей стены и ближайшего соседа (`polygonGap`, повёрнутые контуры учтены). `wallAxisGaps` (#109) отдельно даёт до четырёх отступов по X/Y до граней стен, включая повёрнутый предмет и перегородки.

**Владелец:** поток 1. **Пакеты:** G01.
