# src/domain/relations

Назначение оборудования самой глубокой зоне и пересчёт связей.

**Владелец:** поток 1. **Пакеты:** G02.
Реализовано пакетом G02. Объект принадлежит самой глубокой зоне, которая содержит его отпечаток целиком; неоднозначность и отсутствие зоны дают `null` с диагностикой, а не догадку. `prepareZones(zones)` готовит пригодность, охват и глубину зон один раз на план; `resolveZone` принимает индекс третьим параметром (D-205).

## Граница модуля

Потребляет contracts и geometry. Изменение модели возвращает результат, не мутирует store.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `index.ts` — G02.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
