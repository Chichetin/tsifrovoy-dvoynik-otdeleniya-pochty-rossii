# src/domain/catalog

Проверка структуры и согласованности расширяемых справочников.

**Владелец:** поток 3. **Пакеты:** C01.
Реализовано пакетом C01: `validateCatalog` и доступ к типам. Ничего специфичного для конкретного типа оборудования в коде быть не должно — такие знания живут в `data/catalog/*.json`.

## Граница модуля

Конкретные типы и правила находятся в data/catalog. Потребляет contracts; не импортирует UI или store.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `index.ts` — C01.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
