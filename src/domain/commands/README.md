# src/domain/commands

Атомарные изменения документа с проверкой структурных инвариантов.

**Владелец:** поток 1. **Пакеты:** S01 — реализован.

`applyCommand(plan, command)` — чистая функция: структурные ошибки (неизвестный id,
занятый id, запертый слой, атрибут не того типа) отклоняются, геометрические
сохраняются как диагностируемое состояние. Коды модуля — `COMMAND_ISSUE_CODES`.

## Граница модуля

Потребляет contracts, catalog, geometry и relations. Не хранит историю или React-состояние: это src/state.

## Файлы

- `index.ts` — S01: `applyCommand`, `idOwners`, `COMMAND_ISSUE_CODES`, `takenIds`, `freshId`; единственный вход модуля.
- `ids.ts` — `nextFreeId(prefix, taken)`: единственное правило выдачи `<prefix><n>` для всех инструментов (D-198).
- `room-walls.ts` — наружные стены следуют за контуром помещения (D-134): `room.set`
  пересобирает их по рёбрам нового контура, перегородки и их проёмы не трогает, а проём
  наружной стены переезжает на своё ребро, найденное по вершинам. Наружность — признак
  геометрии, в модели его нет. Вызывается только из `index.ts`.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
