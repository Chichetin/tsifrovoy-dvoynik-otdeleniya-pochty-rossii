# src/domain/commands

Атомарные изменения документа с проверкой структурных инвариантов.

**Владелец:** поток 1. **Пакеты:** S01 — реализован.

`applyCommand(plan, command, retired?)` — чистая функция (третий параметр — удалённые в сессии id, чтобы `room.set` не выдал их новым стенам, D-204; набор — снимок на входе, удаления внутри того же `batch` в него не попадают): структурные ошибки (неизвестный id,
занятый id, запертый слой, атрибут не того типа) отклоняются, геометрические
сохраняются как диагностируемое состояние. Коды модуля — `COMMAND_ISSUE_CODES`.

`zone.put` новой зоны без заявленного родителя берёт вложенность из геометрии — тем же `parentZoneFor` из relations, что и импорт (D-199, D-223); заявленный родитель и снятый родитель существующей зоны остаются выбором человека.

`opening.put` отклоняет ширину больше длины собственной стены (`COMMAND_ISSUE_CODES.OPENING_TOO_WIDE`, `path: '/width_m'`, D-267): ширина задаётся полем или крайними ручками на плане, перемещение — центральной ручкой (D-328).

## Граница модуля

Потребляет contracts, catalog, geometry и relations. Не хранит историю или React-состояние: это src/state.

## Файлы

- `index.ts` — S01: `applyCommand`, `idOwners`, `COMMAND_ISSUE_CODES`, `takenIds`, `freshId`; единственный вход модуля.
- `ids.ts` — `nextFreeId(prefix, taken)`: единственное правило выдачи `<prefix><n>` для всех инструментов (D-198).

- `inventory-number.ts` — `nextInventoryNumber(plan, taken?)`: следующий номер серии плана (префикс большинства, наибольший + 1 с его шириной, пропуски не заполняются, без номеров — `ИНВ-0001`); `withInventoryNumber(plan, object)` ставит его новому физическому объекту типа с атрибутом внутри той же `object.put`; `carriesInventoryNumber`, `inventoryNumberOf` — общие с проверкой (D-310).
- `room-walls.ts` — наружные стены следуют за контуром помещения (D-134): `room.set`
  пересобирает их по рёбрам нового контура, перегородки и их проёмы не трогает, а проём
  наружной стены переезжает на своё ребро, найденное по вершинам. Наружность — признак
  геометрии, в модели его нет. Вызывается только из `index.ts`.

**Проверки:** unit-тесты рядом с реализацией; публичные контракты и граничные случаи из карточки пакета.
