# src/domain/metrics

Площадь комнаты и зон, объединение занятого пола, свободная площадь.

**Владелец:** поток 1. **Пакеты:** G03.
Реализовано пакетом G03: `measurePlan(plan)` считает площади помещения и зон. Занятый пол — объединение отпечатков (`polyclip-ts`, D-037), обрезанное контуром помещения и контуром зоны (D-039); принадлежность зоне не используется (D-038). Невычислимый полигон даёт отказ, а не выдуманное число.

## Граница модуля

Потребляет contracts и geometry. Формулы не дублируются в UI, 3D и сервере.
