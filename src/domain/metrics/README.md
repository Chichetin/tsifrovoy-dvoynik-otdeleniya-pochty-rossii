# src/domain/metrics

Площадь комнаты и зон, объединение занятого пола, свободная площадь. `zoneOverview` берёт готовый результат площадей и считает объекты и находки по зоне с её потомками; одна находка учитывается один раз.

**Владелец:** поток 1. **Пакеты:** G03.

## Граница модуля

Потребляет contracts и geometry. Формулы не дублируются в UI, 3D и сервере.
