# src/features/equipment

Фигуры оборудования, создание экземпляра, перемещение/поворот и preview рекомендации.

**Владелец:** поток 2. **Пакеты:** U04.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts и geometry. Одна команда на завершённый жест; preview не добавляет объект в документ.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `EquipmentLayer.tsx` — U04.
- `transform.ts` — U04.
- `use-equipment-tool-controller.ts` — U04.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
