# src/features/equipment

Фигуры оборудования, создание экземпляра, перемещение/поворот и preview рекомендации.

**Владелец:** поток 2. **Пакеты:** U04.
Реализовано пакетом U04: `EquipmentLayer.tsx` рисует объекты по `size_m`, символу и цвету справочника; у выбранного объекта на показанном и незапертом слое — восемь ручек размера и ручка поворота перед передней кромкой; перенос, поворот (Shift — шаг 15°) и размер — по одной команде `object.put` на жест, Delete/Backspace — `object.delete`. `use-equipment-tool-controller.ts` ставит объект выбранного типа кликом.

## Граница модуля

Потребляет contracts и geometry. Одна команда на завершённый жест; preview не добавляет объект в документ. Указатель переводится в метры только через `screenToModel` из `src/domain/geometry`; вся арифметика жестов — чистые функции `transform.ts` (D-075…D-078).

## Файлы

- `EquipmentLayer.tsx` — фигуры, ручки, preview жеста, клавиши Delete/Backspace и Escape.
- `transform.ts` — поворот по указателю, размер за ручку с неподвижной противоположной стороной, минимум 0,1 м, округление до сантиметра и 0,1°; `transform.test.ts` — 15 проверок, включая один экранный жест через три масштаба.
- `use-equipment-tool-controller.ts` — постановка объекта из библиотеки.

**Проверки:** `tests/e2e/equipment.spec.ts` (повороты 90°/37°, перенос после zoom, размер без полей масштаба в файле, одно «Отменить» на жест, скрытый и запертый слой, стеллаж из `example_plan.json` через сохранение и повторное открытие); общий сценарий — Q01.
