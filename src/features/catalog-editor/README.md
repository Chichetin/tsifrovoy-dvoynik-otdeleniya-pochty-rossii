# src/features/catalog-editor

Панель «Справочник»: типы оборудования, их атрибуты и правила комплектования правятся
из интерфейса, без правки JSON (D-139).

**Владелец:** поток 3.

## Граница модуля

`catalog-edit.ts` — чистые функции над `Catalog`: собирают новый каталог, ничего не
применяют. Применяет одна команда `catalog.replace`, и она же отказывает: тип, которым
пользуется объект; обязательный атрибут без умолчания; дубли и битые ссылки. Панель
показывает отказ у себя. Ни стора, ни документа модуль не хранит.

## Файлы

- `catalog-edit.ts` — добавить/удалить тип, атрибут, правило; `slugId` — читаемый
  идентификатор из подписи.
- `CatalogPanel.tsx` — формы и списки; каждое действие — `catalog.replace`.

**Проверки:** `catalog-edit.test.ts` (сквозь `applyCommand`), `tests/e2e/catalog-editor.spec.ts`.
