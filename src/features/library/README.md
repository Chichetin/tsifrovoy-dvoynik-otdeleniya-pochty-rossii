# src/features/library

Поиск и категории библиотеки, выбор типа для размещения.

**Владелец:** поток 2. **Пакеты:** U07.

## Граница модуля

Потребляет contracts. Выдаёт Tool object.place; создание объекта выполняет контроллер U04, соединённый через app. Активный тип получает постоянную подсветку и `aria-pressed`; успешная установка одноразовая и возвращает режим «Выбор», а после отказа тип остаётся активным для повторной попытки (D-231). Повторный клик по активному типу снимает режим установки и возвращает «Выбор» (D-232).
