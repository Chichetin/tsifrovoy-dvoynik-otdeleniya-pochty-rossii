# src/features/library

Поиск и категории библиотеки, выбор типа для размещения.

**Владелец:** поток 2. **Пакеты:** U07.
Реализовано пакетом U07: список типов из справочника, сгруппированный его же категориями, с поиском; клик выбирает инструмент установки. Ни одного названия типа в коде нет.

## Граница модуля

Потребляет contracts. Выдаёт Tool object.place; создание объекта выполняет контроллер U04, соединённый через app. Активный тип получает постоянную подсветку и `aria-pressed`; успешная установка одноразовая и возвращает режим «Выбор», а после отказа тип остаётся активным для повторной попытки (D-231). Повторный клик по активному типу снимает режим установки и возвращает «Выбор» (D-232).

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `LibraryPanel.tsx` — U07; габариты через `domain/number-format` (D-197).
- `LibraryPanel.test.tsx` — запись габарита, подпись поиска, скрытый от диктора образец цвета, доступное состояние активного типа.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
