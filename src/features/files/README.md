# src/features/files

Загрузка файла, подготовка скачивания, подтверждение замены dirty-документа.

**Владелец:** поток 3. **Пакеты:** IO03.
Реализовано пакетом IO03: кнопка «Открыть» принимает оба формата — наш версионированный JSON и `example_plan.json` организаторов (`readPlanFile`, D-086), импорт подписан на экране вместе с допущениями (D-087); скачивание не заявляет запись на диск; несохранённые правки защищены подтверждением, а ошибка чтения не подменяет открытый документ. Локальный черновик браузера предлагается при старте и восстанавливается как несохранённый план (D-088, D-089); его хранилище — `persistence/browser-draft.ts`, в тестах и на стендах подменяется или отключается свойством `storage` (`null` — без черновика, объект `DraftStorage` — своё хранилище; покрыто `FileControls.test.tsx`). Запись черновика молчит, только пока предложение без ответа и документ не тронут: «Новый», «Открыть», «Восстановить», «Удалить» и первая же правка возвращают запись (D-104). Заменять черновиком непустой документ редактор просит подтвердить, даже если тот только что открыт из файла и по `dirty` считается сохранённым (D-105).

## Граница модуля

Потребляет contracts и persistence. replaceDocument/markExported получает callback; не сериализует сцену холста.
