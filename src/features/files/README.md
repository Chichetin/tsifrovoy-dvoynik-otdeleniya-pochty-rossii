# src/features/files

Загрузка файла, подготовка скачивания, подтверждение замены dirty-документа.

**Владелец:** поток 3. **Пакеты:** IO03.
Реализовано пакетом IO03: кнопка «Открыть» принимает оба формата — наш версионированный JSON и `example_plan.json` организаторов (`readPlanFile`, D-086), импорт подписан на экране вместе с допущениями (D-087); скачивание не заявляет запись на диск; несохранённые правки защищены подтверждением, а ошибка чтения не подменяет открытый документ. Локальный черновик браузера предлагается при старте и восстанавливается как несохранённый план (D-088, D-089); его хранилище — `persistence/browser-draft.ts`, в тестах и на стендах отключается свойством `storage={null}`.

## Граница модуля

Потребляет contracts и persistence. replaceDocument/markExported получает callback; не сериализует сцену холста.
