# src/features/validation

Список нарушений, повторная проверка, подсветка и переход к проблеме.

**Владелец:** поток 3. **Пакеты:** V02.

## Граница модуля

Получает `ValidationIssue[]` через props — локальное расширение `Issue` с необязательными `ruleIds`, которое не меняет общий контракт и формат плана. Для рисования использует geometry, диагностику не пересчитывает в JSX.

«Почему?» у находки (`finding-why.ts`, #33) читает данные: правило справочника по `ruleIds` (обоснование, источник, все параметры записи) или `PHYSICS_RULES` по коду. Для прочих проверок геометрии описания в domain нет — их заменяет короткая таблица в `finding-why.ts`. «Показать вариант исправления» вызывает `findPlacements` из `domain/advice` и отдаёт кандидата в необязательный проп `onPreview`.
