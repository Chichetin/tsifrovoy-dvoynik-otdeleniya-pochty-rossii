# src/features/validation

Список нарушений, повторная проверка, подсветка и переход к проблеме.

**Владелец:** поток 3. **Пакеты:** V02.
Реализовано пакетом V02 частично: список находок `validatePlan`, ошибки выше предупреждений, переход к объекту по `id`. `IssueLayer.tsx` подсвечивает на холсте полигоны находок выделенной сущности, отбор — `issue-highlight.ts` (D-117).

## Граница модуля

Получает Issue[] через props. Для рисования использует geometry, диагностику не пересчитывает в JSX.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `ValidationPanel.tsx` — V02.
- `IssueOverlay.tsx` — V02.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
