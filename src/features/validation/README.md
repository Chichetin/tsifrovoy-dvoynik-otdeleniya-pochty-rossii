# src/features/validation

Список нарушений, повторная проверка, подсветка и переход к проблеме.

**Владелец:** поток 3. **Пакеты:** V02.
Реализовано пакетом V02: список находок `validatePlan`, ошибки выше предупреждений, переход к объекту по `id`. В находке стоит название объекта, зоны или слоя из открытого документа, `id` — рядом вторичным текстом (D-122); документ приходит из композиции приложения, без него в находке остаётся только `id` (D-124). `IssueLayer.tsx` без клика ставит маркер с числом находок и цветом серьёзности у каждой сущности, которую находка называет первой, а полигоны находок выделенной сущности заливает и обводит сплошным контуром с белой каймой; отбор — `issue-highlight.ts` (`highlightsFor`, `issueMarkers`, `markerAnchor`; D-117, D-138). Маркеры — узлы Konva `name="issue-marker"`, e2e `tests/e2e/issues-on-plan.spec.ts` читает их через `window.Konva`.

## Граница модуля

Получает Issue[] через props. Для рисования использует geometry, диагностику не пересчитывает в JSX.
