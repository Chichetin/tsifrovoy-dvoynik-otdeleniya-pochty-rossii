# src/features/properties

Свойства помещения, зоны, объекта, перегородки и проёма; числовой ввод, динамические
атрибуты из каталога.

**Владелец:** поток 2. **Пакеты:** U06.

Карточка помещения (клик по полу) правит название плана (`plan.rename` — из него
берётся имя файла) и высоту потолка (`room.setCeiling` — наружные стены поднимаются
вместе с ним, перегородки нет); контур тянется на плане, числами не дублируется (D-152).

## Граница модуля

Потребляет contracts. Поля строятся из AttributeDef, ID не редактируется, ошибка ввода не теряет документ.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `PropertiesPanel.tsx` — U06.
