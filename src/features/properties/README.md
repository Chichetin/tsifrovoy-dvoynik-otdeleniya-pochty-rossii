# src/features/properties

Свойства помещения, зоны, объекта, перегородки и проёма; числовой ввод, динамические
атрибуты из каталога.

**Владелец:** поток 2. **Пакеты:** U06.

Карточка помещения (клик по полу) правит название плана (`plan.rename` — из него
берётся имя файла) и высоту потолка (`room.setCeiling` — наружные стены поднимаются
вместе с ним, перегородки нет); контур тянется на плане, числами не дублируется (D-152).
Площадь по контуру карточка берёт у `ringArea`, а не у `polygonArea`: на контуре, который
пересекает сам себя, площади нет, и вместо ровного «0,00 м²» карточка говорит то же, что
панель площадей, — «контур пересекает сам себя: площадь по нему не считается» (D-242).

Карточка не показывает `id` (D-278): он есть в перечне и в файле, а на `<section aria-label="Свойства">` лежит атрибутом `data-entity-id` — по нему выбранное узнают e2e и замер. Зона объекта — строкой «Зона: <название зоны>», вне зон или по висячей ссылке — «Зона: вне зон», у зоны без имени — её `id`, как в перечне.

Во время переноса объекта поля X/Y следуют за рукой (D-220). Карточка читает внешний канал предпросмотра через `useSyncExternalStore`; после броска или Escape канал очищается, и источником снова становится документ. Изменение координат мышью по-прежнему создаёт одну команду только в конце жеста.

Поля, чьи значения рисует информационный слой («Загрузка зоны, %», «Сотрудников в смене», угол и дальность камеры), никакой пометки условности не несут: участник запретил её возвращать (D-281, отменяет видимую часть D-276). Синтетичность чисел раскрыта в README и презентации.

Форма объекта (D-279): у объекта с собственной формой (не совпадающей с формой типа, `hasOwnShape`) карточка показывает число вершин, кнопку «Сбросить форму к типу» (`object.put` без `outline` — команда возвращает форму типа) и «Сохранить форму как новый тип» с полем названия: `shapeTypeFrom` (`shape-type.ts`) копирует исходный тип, берёт контур и размер объекта, `id` `ot_shape_<n>`, источник «Допущение команды…» — одна команда `catalog.replace`. Пустое название — ошибка у поля. У объекта с формой типа — подсказка, что форму правят двойным щелчком на плане. Проверки — `shape-type.test.tsx` (4).

## Граница модуля

Потребляет contracts. Поля строятся из AttributeDef, ID не редактируется, ошибка ввода не теряет документ.
