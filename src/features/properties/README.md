# src/features/properties

Свойства объекта/зоны, числовой ввод, динамические атрибуты из каталога.

**Владелец:** поток 2. **Пакеты:** U06.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts. Поля строятся из AttributeDef, ID не редактируется, ошибка ввода не теряет документ.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `PropertiesPanel.tsx` — U06.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
