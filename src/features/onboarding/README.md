# src/features/onboarding

Мини-обучение при первом входе: четыре шага по сценарию проверяющего с подсветкой
настоящих панелей.

**Владелец:** поток 2. **Пакет:** UX-очередь №2 (`HANDOFF.md`), решение D-195.

## Граница модуля

Не импортирует соседние модули и store. Панели находит только по `data-tour`,
который ставит `src/app/App.tsx` (`files`, `tools`, `side-left`, `side-right`);
нет панели на экране — шаг показывается без подсветки. Открывать ли окно, решает
приложение (`shouldShowTour`), итог возвращается через `onClose`. В файл плана
ничего не пишет.
