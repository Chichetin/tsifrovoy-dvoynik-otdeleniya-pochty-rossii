# src/features/assistant

Запрос сценария, карточки рекомендаций, before/after, preview и fallback.

**Владелец:** поток 4. **Пакеты:** A06.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts и domain/advice для локального fallback; fetch только к своему /api/advice. Ключи и прямые вызовы провайдера запрещены.
Серверный 429 ограничивает вызовы модели, но не лишает пользователя расчёта:
`advice-client.ts` пересчитывает рекомендации в браузере и явно помечает режим
«Без LLM». Ошибки 400/422 остаются ошибками плана или запроса.
В «Комплектовании» панель показывает название типа оборудования и зоны из
справочника текущего плана рядом с проверенными числами рекомендации.
В «Найти место» у каждого варианта названа его зона — имя и `id` из плана
(`data-testid="candidate-zone"`), либо «вне зон» (D-186).
Необязательное пожелание пользователя (D-222) модель использует только для выбора
среди уже рассчитанных кодов причины и вариантов. Оно не расширяет расчёт и не может
добавить число или факт; без LLM панель прямо пишет, что пожелание не учитывалось.

## Отдельный исходный файл (#5)

ComparisonPanel в сценарии «Эффект изменений» показывает таблицу buildPlanComparison. useComparisonSource читает источник через readPlanFile и защищает от поздних ответов, не обращаясь к store. App передаёт источник сценарию compare и очищает его при открытии/новом документе. Исходный файл не меняет save baseline/dirty/undo; чат сохраняет собственную точку отсчёта. Для разных ID планов только сводные показатели и предупреждение, сценарный запрос отключён. Список изменений включает предметы, зоны, слои и помещение, но не стены/проёмы/справочник.
