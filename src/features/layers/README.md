# src/features/layers

Панель слоёв: CRUD, видимость, блокировка, порядок и перенос содержимого;
информационные слои поверх плана с легендой из справочника.

**Владелец:** поток 2. **Пакеты:** U05, U05-ux (D-161).

## Граница модуля

Потребляет contracts. Изменения идут через Command; скрытие не меняет инвентаризацию.
Информационный слой документ не меняет: он читает атрибуты зон и объектов, а
цвета, единицы и порог шкалы берёт из `catalog.layerTypes`.

## Файлы

- `LayersPanel.tsx` — список слоёв, флажок «Показывать», легенда и таблица значений.
- `InformationLayer.tsx` — рисование информационных слоёв на холсте Konva, легенда холста.
- `legend.ts` — легенда слоя из справочника (шкала, порог, цвет, единица).
- `label-layout.ts` — раскладка подписей без наложения.
- `heat-regions.ts` — какая зона красит какую часть плана при вложенности (D-136).

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
