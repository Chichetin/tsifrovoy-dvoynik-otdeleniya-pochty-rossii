# src/features/editor

Холст, сетка, zoom/pan, выбор, focus и перевод pointer в мировые координаты.

**Владелец:** поток 2. **Пакеты:** U02.
Реализовано пакетом U02: `viewport.ts` — чистая арифметика pan/zoom/вписывания (zoom держит точку под курсором), `focus.ts` — что показать по `Ref` и куда для этого посмотреть, `EditorCanvas.tsx` — сетка, перевод pointer в метры и слои фигур через children. Фигуры здесь не рисуются; единственная собственная — кольцо подсветки найденного, оно живёт 1,6 с и документа не касается.

Что холст делает сам (D-127…D-130):

- вписывает каждый новый документ целиком — помещение вместе с тем, что вынесено за его стены; правка плана масштаб не сбрасывает;
- кнопка «Вписать» на холсте и клавиша `F` (по `event.code`, не по букве) возвращают весь план;
- отвечает на `session.focus`: вид не двигается, если фигура видна целиком с полями 32 px; иначе перецентровка тем же масштабом, а при нехватке места — вписывание по фигуре;
- публикует текущий вид в `data-visible` (метры) и подсвеченную ссылку в `data-focus` — по ним считают браузерные проверки;
- кнопка «Картинка PNG» выгружает весь план картинкой для согласования (D-136): охват как у «Вписать», белый фон, название плана и «числа синтетические» для видимых информационных слоёв; без сетки, ручек и рамки выделения. Снимок делается с вписанного вида без выделения, вид и выделение возвращаются до отрисовки кадра; ошибка сборки PNG показывается на холсте.

## Граница модуля

Потребляет contracts, geometry и Konva. Принимает figures через children; бизнес-логику инструментов получает через callbacks.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `EditorCanvas.tsx` — U02.
- `viewport.ts` — U02.
- `focus.ts` — U02 (переход к объекту и охват плана).
- `export.ts` — U02: рамка выгрузки, разрешение, имя файла, подпись над планом (чистые функции, `export.test.ts`).
- `export-image.ts` — U02: снимок рамки холста в PNG и скачивание (браузер, проверяется `tests/e2e/plan-export.spec.ts`).

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
