# src/features/editor

Холст, сетка, zoom/pan, выбор, focus и перевод pointer в мировые координаты.

**Владелец:** поток 2. **Пакеты:** U02.

## Граница модуля

Потребляет contracts, geometry и Konva. Принимает figures через children; бизнес-логику инструментов получает через callbacks.

Перетаскивание плана и колесо двигают и масштабируют сцену Konva, а не план (#223, #190). `onViewport` приходит один раз: при отпускании кнопки или через 120 мс без движения. До этого слои рисуют по прежнему `session.viewport`.
