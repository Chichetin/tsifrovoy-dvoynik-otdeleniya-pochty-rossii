# src/features/editor

Холст, сетка, zoom/pan, выбор, focus и перевод pointer в мировые координаты.

**Владелец:** поток 2. **Пакеты:** U02.

## Граница модуля

Потребляет contracts, geometry и Konva. Принимает figures через children; бизнес-логику инструментов получает через callbacks.

Панорама и колесо двигают и масштабируют сцену Konva, а не план (#190). `onViewport` приходит один раз: при отпускании кнопки или через 120 мс после последнего щелчка колеса (#223). До этого слои рисуют по прежнему `session.viewport`, а сетка — по текущему виду.
