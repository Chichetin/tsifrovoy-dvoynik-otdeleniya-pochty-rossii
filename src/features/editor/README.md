# src/features/editor

Холст, сетка, zoom/pan, выбор, focus и перевод pointer в мировые координаты.

**Владелец:** поток 2. **Пакеты:** U02.

## Граница модуля

Потребляет contracts, geometry и Konva. Принимает figures через children; бизнес-логику инструментов получает через callbacks.

Панорама и колесо не перерисовывают приложение (#190, #223). `onViewport` приходит один раз: при отпускании кнопки или через 120 мс после последнего щелчка колеса. До этого слои нарисованы по прежнему `session.viewport`, а сетка — по текущему виду. План до 2000 узлов Konva двигается трансформацией сцены и одной перерисовкой за кадр. Больший план двигается CSS-трансформацией уже нарисованных холстов, без перерисовки.
