# src/features/editor

Холст, сетка, zoom/pan, выбор, focus и перевод pointer в мировые координаты.

**Владелец:** поток 2. **Пакеты:** U02.
Реализовано пакетом U02: `viewport.ts` — чистая арифметика pan/zoom/вписывания (zoom держит точку под курсором), `focus.ts` — что показать по `Ref` и куда для этого посмотреть, `hotkeys.ts` — какие нажатия принадлежат плану, а какие браузеру и полям ввода, `EditorCanvas.tsx` — сетка, перевод pointer в метры и слои фигур через children. Фигуры здесь не рисуются; единственная собственная — кольцо подсветки найденного, оно живёт 1,6 с и документа не касается.

Что холст делает сам (D-127…D-130):

- вписывает каждый новый документ целиком — помещение вместе с тем, что вынесено за его стены; правка плана масштаб не сбрасывает;
- кнопка «Вписать» и подпись масштаба стоят одной накладкой в правом нижнем углу, чтобы остальные углы холста принадлежали плану (D-161);
- двухпальцевый свайп тачпада, обычное колесо и средняя кнопка мыши панорамируют, а `Ctrl`+колесо и pinch-жест тачпада масштабируют вокруг указателя; `Ctrl`+`+`/`Ctrl`+`-` меняют масштаб вокруг центра холста (D-235);
- клавиша `F` возвращает весь план — по `event.code`, не по букве, и только без модификаторов: Shift+F, Ctrl+F и Alt+F холст не трогает (D-128, D-161); `Ctrl+Z`, `Ctrl+Y` и `Ctrl+Shift+Z` — `historyHotkey`, отмена и повтор истории store, слушатель подключает `src/app/App.tsx` (D-183);
- отвечает на `session.focus`: вид не двигается, если фигура видна целиком с полями 32 px; иначе перецентровка тем же масштабом, а при нехватке места — вписывание по фигуре;
- публикует текущий вид в `data-visible` (метры) и подсвеченную ссылку в `data-focus` — по ним считают браузерные проверки.

## Граница модуля

Потребляет contracts, geometry и Konva. Принимает figures через children; бизнес-логику инструментов получает через callbacks.
