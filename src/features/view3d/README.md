# src/features/view3d

Производная сцена Three.js и её показ с общей selection.

**Владелец:** поток 3. **Пакеты:** D01 (сделан).

## Граница модуля

Потребляет contracts и `src/domain/geometry` (публичный `index.ts`), получает
`PlanDocument` и `selection` через `View3DProps`. Хранит только состояние камеры и
ресурсы сцены, не второй редактируемый план: сцена строится заново из документа при
каждом его изменении (D-080, D-083).

## Известные ограничения

- #54: при ошибке загрузки доступна кнопка повторной загрузки без потери плана.
  `module-recovery.ts` допускает только URL View3DCanvas с текущего origin;
  успешный модуль кешируется при переходах 2D/3D. Браузер должен сообщить URL
  неудачной загрузки для обхода своего кеша. Удалённый чанк повтором не восстановить.

- Объект рисуется моделью своего типа (`models.ts`, файлы `public/models/*.glb`).
  Подгонка под размер — `model-fit.ts`, правило лежит в самой модели (D-357).
  Объекты одной модели и одного размера — один `InstancedMesh` на деталь.
  Невидимая призма под моделью ловит клик. Нет файла или своя форма (D-277) —
  призма, как раньше.
- Стена между камерой и центром обзора становится прозрачной и не ловит клик.
- Потолок не рисуется (закрыл бы интерьер).
- Клик по объёму в 3D выбирает его тем же `onSelect`, что и 2D, инвентаризация и
  панель слоёв: одна общая `selection`, без второго состояния выбора в 3D.
- Сырой `example_plan.json` открывается через импорт формата организаторов
  (`src/persistence/organizer-import.ts`), а не напрямую кнопкой «Открыть».
