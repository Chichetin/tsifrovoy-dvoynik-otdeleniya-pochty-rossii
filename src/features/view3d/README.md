# src/features/view3d

Производная сцена Three.js и её показ с общей selection.

**Владелец:** поток 3. **Пакеты:** D01.
Это место для реализации; пока здесь размещена только карта модуля.

## Граница модуля

Потребляет contracts и geometry, получает PlanDocument через props. Хранит только состояние камеры и ресурсы сцены, не второй редактируемый план.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `scene.ts` — D01.
- `View3D.tsx` — D01.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
