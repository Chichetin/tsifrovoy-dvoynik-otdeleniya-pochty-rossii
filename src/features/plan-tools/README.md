# src/features/plan-tools

Инструменты границы помещения, зон, стен и проёмов; их геометрический слой.

**Владелец:** поток 2. **Пакеты:** U03.

Реализовано пакетом U03:

- `PlanGeometryLayer.tsx` — помещение, зоны, стены и проёмы на холсте; у выбранной фигуры ручки: вершины контура (тянуть, клик по ребру добавляет вершину, двойной клик по ручке убирает), концы перегородки, середина проёма. Жест даёт одну команду на отпускании, самопересечение отклоняется (D-070, D-071).
- `use-plan-tool-controller.ts` — рисование контура по точкам, замыкание кликом по первой; новая зона получает родителя по геометрии (D-073).
- `PlanTools.tsx` — выбор инструмента, кнопка удаления выбранной зоны, перегородки или проёма (то же делает Delete) и строка отказа жеста.
- `vertex-edit.ts` — чистые функции жестов: перенос, вставка и удаление вершины, поиск ближайшего ребра, сдвиг конца стены и проёма вдоль неё, выбор родителя контура.
- `notice.ts` — канал сообщения об отказе жеста между слоем на холсте и панелью (D-072).

Не сделано: инструментов рисования новых перегородок и проёмов нет — они приходят из шаблона нового плана или из открытого файла и только правятся; родитель зоны при правке контура не пересчитывается, его меняет карточка свойств (U06).

## Граница модуля

Потребляет contracts и geometry. Контроллер инструмента выдаёт Command, а не пишет в store. App передаёт события через ToolController.
