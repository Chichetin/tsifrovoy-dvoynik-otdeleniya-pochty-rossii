# src/features/plan-tools

Инструменты границы помещения, зон, стен и проёмов; их геометрический слой.

**Владелец:** поток 2. **Пакеты:** U03.

## Граница модуля

Потребляет contracts и geometry. Контроллер инструмента выдаёт Command, а не пишет в store. App передаёт события через ToolController. Ручки перегородки видны только при `wallEditing` (переключатель «Изменить перегородку», состояние держит App).
