# src/features/inventory

Границы колонок в перечне объектов, разрезе по зонам и таблице площадей можно тянуть мышью или двигать стрелками с клавиатуры (D-213). `resizable-columns.tsx` хранит отдельную процентную раскладку каждой таблицы в `localStorage`, не даёт соседней колонке стать уже 10% и возвращает исходные ширины двойным щелчком; повреждённые сохранённые значения безопасно игнорируются.

Таблица оборудования, фильтры, площади и переход к объекту.

**Владелец:** поток 3. **Пакеты:** M02.

## Граница модуля

Получает Inventory и Result<Metrics> через props. Формулы в domain; выбор/фокус через callbacks. Названия — из `document` в пропсах, который передаёт композиция приложения; без него панель работает и показывает `id` (D-124). Состояние фильтра живёт в компоненте и документ не меняет. Флажок «Только ТО» оставляет объекты, у которых срок ТО прошёл или наступит в 14 дней; срок считает `domain/validation`, тот же, что у проверки. Столбцы атрибутов берутся из справочника плана; выбор видимых столбцов и CSV — `persistence/inventory-csv.ts`, его же читает «Экспорт → CSV».
