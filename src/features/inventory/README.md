# src/features/inventory

Таблица оборудования, фильтры, площади и переход к объекту.

**Владелец:** поток 3. **Пакеты:** M02.
Реализовано пакетом M02 частично: таблица объектов и подсчёт по зонам из `buildInventory`, переход к объекту по клику. Формул в разметке нет. Метрики площадей — после G03.

## Граница модуля

Получает Inventory и Result<Metrics> через props. Формулы в domain; выбор/фокус через callbacks.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `InventoryPanel.tsx` — M02.
- `MetricsPanel.tsx` — M02.

**Проверки:** собственный browser harness в `tests/harness/<ID>.tsx`, spec в `tests/e2e/`; после подключения — общий Q01.
