# Презентация защиты — «Цифровой двойник ОПС», команда «ИИ-бланки»

HTML-слайды без сборки. Сцена 1920×1080, масштаб под окно. Задача — #19.

## Запуск

```bash
cd presentation && python3 -m http.server 8765
```

Откройте <http://127.0.0.1:8765/>. Выберите стиль. Все 6 стилей показывают одни и те же
слайды: `seam`, `route`, `panel`, `poster`, `stamp`, `ginger`.

## Клавиши

| Клавиша | Действие |
|---|---|
| `→`, `Space`, `PageDown` | следующий шаг или слайд |
| `←`, `PageUp` | назад |
| `Home`, `End` | первый и последний основной слайд |
| `↓` или `Q` | запасные слайды; `Esc` или `↑` — обратно |
| `F` | полный экран |
| `N`, `T`, `R` | заметки докладчика, таймер 07:00, сброс таймера |

`?static` показывает все шаги сразу и останавливает движение. Из этого режима делается PDF.
`#s5` или `#s5.2` открывает слайд и шаг.

## Демо

- Слайд 12 — ролик `assets/demo/demo.mp4`: 44 с, 1080p, без звука.
- В ролике: в 2D терминал очереди перетаскивают к входу, и балл растёт с 87 до 97. Потом
  включают слой камер. В 3D — облёт сбоку и вид глазами посетителя.
- Слайд открылся — ролик играет с начала, страница переходит в полный экран. Слайд
  закрылся — ролик на паузе.
- Без нажатия клавиши браузер не даёт перейти в полный экран: при открытии по ссылке
  `#s12` нажмите `F`.
- Ролик снят через Playwright на демо-плане `public/demo/before.json`, без рамок и
  подписей. Заставка в `?static` — `assets/demo/demo-poster.webp`.

## Где править

- Тексты и порядок слайдов — `shared/slides.js`. Факты берём только из кода и документов
  проекта.
- Раскладка — `shared/layout.css`. Вид стиля — `<стиль>/styles.css`.
- Навигация и автозапуск ролика — `shared/app.js`. Движение — `shared/motion-core.js`.
- Не ломайте хуки движения: `data-step` (не больше 4 на слайд), `data-count`,
  `data-draw`, `data-links`, `.ln`, `.in`. Текст на сцене — не меньше 22 px.
