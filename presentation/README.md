Снимки и ролики сними через Playwright на демо-плане `demo/before.json` из `main` на SHA
защиты. Окно 1920×1080, интерфейс без черновиков и лишних всплывающих окон.

- Снимки (`presentation/assets/shots/*.webp`). Есть: `plan-2d`, `plan-check`, `findings`,

- Ролики (`presentation/assets/clips/*.webm`, 3–5 с, без звука, до ~1,5 МБ каждый):
  1. `silhouette.webm` — объект из библиотеки ведут к стене: силуэт зелёный → жёлтый →
     красный, рядом причина отказа.

  3. `apply-fix.webm` — ассистент показывает вариант полупрозрачно → «Применить» →
     значок находки исчезает.
- Правило движка: бесконечных циклов нет. Ролик играет **один раз** при показе своего
  шага (`muted playsinline`, без `loop`), потом стоит на последнем кадре. В `?static` и при
  `prefers-reduced-motion` — постер (последний кадр как `.webp`).

### 9. Как работает ассистент (пайплайн)

- Заголовок: «Модель объясняет,» / «код считает»
- Схема из ветки (слайд `s5`): две дорожки-таблетки «Модель» и «Код», узлы
  Вопрос → Выбирает сценарий → Считает → Объясняет → Проверяет → Вариант на плане. Пакет
  бежит по связям (`data-links`, `data-packet`), по шагу на звено. Пунктирная ветка от
  «Проверяет» → «Расчёт «Без LLM»».
- Справа или снизу — три принципа из PDF, появляются после схемы:
  1. **Числа считает код** — «Площади, поиск места, правила — функции с тестами.»

     API — ответ «Без LLM». После правки код сам говорит, что изменилось.»
  3. **Ничего не двигает сам** — «Вариант полупрозрачный. Ставит только «Применить».
     Отмена — Ctrl+Z.»
- Маленький кадр `assistant-journal` (журнал шагов агента) у узла «Считает».
- Заметка: «Модель не считает. Она выбирает инструмент и объясняет. Площади, места и
  правила считает код. Потом код проверяет ответ модели: все `id` существуют, числа
  совпадают. Если нет — показываем расчёт с пометкой «Без LLM». И ассистент ничего не
  меняет без кнопки «Применить».»
