# data/catalog

JSON типов оборудования, типов зон и правил комплектования/расстояния.

**Владелец:** поток 3. **Пакеты:** C01.
Наполнено пакетом C01. Новый тип зоны, объекта, атрибут или правило добавляется правкой этих JSON без единой строки кода.

## Граница модуля

Данные проверяются contracts/schema и domain/catalog. Размеры-допущения и источники правил подписываются явно.

## Файлы по плану

Следующие файлы создаются при реализации соответствующих пакетов:

- `object-types.json` — C01.
- `zone-types.json` — C01.
- `rules.json` — C01.
