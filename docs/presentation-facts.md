Скриншоты для PDF нужно снять **после** выбора release commit и повторной
проверки. Кадры: готовый план в 2D с инвентаризацией; карточка свойств с `id`
и атрибутом; нарушение и рекомендация с источником правила; тот же план после
исправления; 3D с видимыми зонами и оборудованием; сохранённый и снова открытый
файл. Под каждым кадром указать commit/среду, а у рекомендаций — режим ответа.
Для чисел E01 использовать его `effect.md` и тест, не считать их вручную по
скриншоту.

Ограничения для последнего слайда: публичный сервис пока не подтверждён (внешняя LLM
подтверждена локально 19.09 и 20.09, на публичном сервере нужен тот же ключ с бюджетом
`LLM_MAX_OUTPUT_TOKENS=4000`, `LLM_TIMEOUT_MS=60000`; ответ рассуждающей модели — 20–40 с); 3D условный; геометрическая проверка не включает доступность
маршрутов и эргономику; правила комплектования команды не являются нормативами
Почты России; на 1000 объектах локальное открытие занимает около 4,5 секунд.
