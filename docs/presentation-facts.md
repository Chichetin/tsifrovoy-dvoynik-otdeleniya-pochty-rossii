# Факты для ручной презентации

Этот файл — проверяемый материал для слайдов. [Черновик PDF](../output/pdf/posttech-digital-twin-2026-09-18.pdf)
собран из этих фактов и снимков работающего локального сервиса; числа и подписи
следует брать только вместе с указанной областью применимости.

| Тезис | Что показать | Откуда факт |
|---|---|---|
| Один редактируемый план для 2D, 3D и инвентаризации | Открыть план, выбрать объект в перечне, переключить 3D и вернуться в 2D | `src/contracts/model.ts`, `src/features/view3d/scene.ts`, [матрица](tz-compliance.md) |
| Сохранение не теряет структуру | Открыть файл, поправить атрибут, сохранить и снова открыть; показать тот же `id` и атрибут | [Q01](verification/e2e.md): локальный собранный сервис 48/48; на кандидате `a2810d0` полный Chrome-набор 55 passed + 5 skipped без деплоя |
| Ассистент объясняет проверенные числа | Показать факт, правило и вариант размещения; назвать режим `fallback` или `llm` по ответу | [README](../README.md#ии-ассистент), `server/advice-route.test.ts` |
| Собственный синтетический проект | Открыть до/после, показать изменение проверки и эффекта | [E01](../demo/README.md) и [эффект](../demo/effect.md), MR !48 слит в `main` |
| Измеренная вместимость редактора | Подписать машину, дату и объём: 100/500/1000 объектов, 10/30/50 зон | [повтор Q02](verification/performance-rc.md): 5 прогонов каждого объёма; 1000 объектов — первое открытие p50 4,52 с на кандидате `17ad4dc` |
| Воспроизводимый локальный запуск | Показать health, SPA и сценарий сохранения из собранного сервиса | [деплой](deployment.md) и [Q01](verification/e2e.md); публичный URL ещё не проверен |

Скриншоты для PDF нужно снять **после** выбора release commit и повторной
проверки. Кадры: готовый план в 2D с инвентаризацией; карточка свойств с `id`
и атрибутом; нарушение и рекомендация с источником правила; тот же план после
исправления; 3D с видимыми зонами и оборудованием; сохранённый и снова открытый
файл. Под каждым кадром указать commit/среду, а у рекомендаций — режим ответа.
Для чисел E01 использовать его `effect.md` и тест, не считать их вручную по
скриншоту.

Ограничения для последнего слайда: публичный сервис и внешняя LLM пока не
подтверждены; 3D условный; геометрическая проверка не включает доступность
маршрутов и эргономику; правила комплектования команды не являются нормативами
Почты России; на 1000 объектах локальное открытие занимает около 4,5 секунд.
