# План: закрепить обязательный UI/UX skill gate

## Цель

Сделать использование UI/UX, браузерных, screenshot и accessibility-скиллов
обязательным процессом для каждой UI-фичи, не меняя продуктовый код.

## Шаги

1. Зафиксировать спецификацию в
   `docs/superpowers/specs/2026-09-21-ui-ux-skill-gate-design.md`.
2. Добавить короткое обязательное правило в `AGENTS.md`, а каноническую матрицу,
   артефакты и критерии готовности — в `CLAUDE.md`.
3. Обновить `docs/agents.md`: связать gate с ролями builder, qa, operator,
   reviewer и integrator, не дублируя всю матрицу в каждом промпте.
4. Записать решение в `docs/decisions.md` и добавить в `HANDOFF.md` итог с
   командами и известными ограничениями.
5. Проверить ссылки, формат Markdown, секреты и upstream-конфликты; для этой
   документационной правки не запускать продуктовый e2e как замену UI-фиче — в
   итоговом отчёте явно указать, что продуктовый код не изменялся.
6. Закоммитить только перечисленные файлы и отправить ветку с Merge Request в
   `main`.

## Не меняем

Продуктовый TypeScript/CSS, тестовые сценарии, зависимости, `docs/tz-compliance.md`
(новый процесс сам по себе не закрывает пункт условий), чужие worktree и
незакоммиченные файлы пользователя.
