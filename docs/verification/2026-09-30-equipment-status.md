# #28 — слой состояния оборудования, приёмка 30.09

Сценарий: готовый синтетический план открывается в 2D; в «Слоях» включается «Состояние оборудования»; видны зелёные рабочие объекты, янтарные в ремонте, красное списанное табло. Кнопка «В ремонте» оставляет в списке нужные объекты, селект меняет состояние, JSON сохраняется и открывается повторно с тем же цветом. Новый пустой план тоже получает тип слоя из справочника. Второй цветовой слой с иной палитрой загружен из JSON без правки компонентов.

UI-бриф и критерии: `docs/plans/2026-09-30-equipment-status.md`. Снимки после правки из живого Edge: `2026-09-30-equipment-status-1280.png` (1280×800) и `2026-09-30-equipment-status-1440.png` (1440×900). Оба осмотрены: знаки и подписи остаются поверх цвета, легенда и фильтр помещаются в левой панели; на 1280 длинный список прокручивается, ничего не перекрывает холст. Фильтр пройден клавишей Enter, селект — нативный, с именем объекта и ID для точного выбора. У кнопок есть `aria-pressed`.

Проверки до MR: `npm.cmd test -- --reporter=dot` — 1675 passed / 1 skipped после регенерации демо; `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build` — exit 0; `PW_CHANNEL=msedge PW_REUSE_SERVER=1 DEV_PORT=5440 npx playwright test tests/e2e/layers.spec.ts tests/e2e/demo.spec.ts tests/e2e/catalog-extension.spec.ts --workers=1 --reporter=dot` — 12 passed. Первый полный e2e-прогон выявил одно старое ожидание ровно пяти слоёв в `layers-ux.spec.ts` после добавления шестого. Ожидание переведено на фактическое число карточек; повторный полный прогон — **235 passed / 5 skipped / 0 failed** (4,2 мин). После доработки карточки свойств отдельный прогон `properties.spec.ts` и `layers.spec.ts` — 20 passed. При первой попытке браузерные тесты не запустились из-за отсутствующего бандлового Chromium; переключили канал на установленный Edge без изменения проекта. После изменения генератора демо старые копии файлов сначала вызвали восемь ожидаемых падений; пересобрали `demo/`, `public/demo/` и ZIP из одного источника, сохранив `mode: llm` существующего проверенного объяснения.
