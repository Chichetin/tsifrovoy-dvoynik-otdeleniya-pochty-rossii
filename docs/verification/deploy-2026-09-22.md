## Площадка

Yandex Cloud, Compute Cloud, зона `ru-central1-d`: Ubuntu 24.04 LTS, 2 vCPU (100 %),
4 ГБ RAM, SSD 20 ГБ, публичный IP. Группа безопасности — `default-sg`, разрешает весь
входящий и исходящий трафик. Развёрнуто по
[инструкции](../hosting-yandex-cloud.md) скриптом `scripts/deploy-vm.sh`: Docker из
репозиториев Ubuntu, `docker compose up --build -d`, один контейнер отдаёт и редактор,
и `/api`.

На сервере `.env` с ключом DeepSeek через Yandex Cloud AI Studio, бюджет модели —
`LLM_TIMEOUT_MS=60000`, `LLM_MAX_OUTPUT_TOKENS=4000` (D-206). Ключ в репозиторий не
попадает: файл создан на машине и в git не входит.

## Ограничения

- **HTTP, без TLS.** Сервис внутренний, данные синтетические, аутентификации нет по
  замыслу — жюри открывает по ссылке.
- Машина открыта наружу целиком (правила `default-sg`), пускает только SSH-ключ.
- Порт 8080: процесс в контейнере работает от пользователя `node` и порты ниже 1024
  занять не может.
- Машину нельзя останавливать до конца проверки: до какой даты сервис должен быть
  доступен, организаторы не сообщили.
