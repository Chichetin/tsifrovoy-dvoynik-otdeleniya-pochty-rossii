# Подсказка наведения — Issue #42

База `1dc3f42`, Максим / Codex, `worktree-42-hover-mode`.

Карточка при установке/рисовании предлагает включить «Выбор» сверху, затем нажать на сам предмет на плане. При выборе/обзоре объясняет, что свойства откроются слева. Переключение инструмента с неподвижной мышью обновляет текст, высоту карточки и её положение в границах холста. Нажатия и жесты оборудования остаются прежними; карточка не получает события мыши.

- `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd run build`: passed. Существующее предупреждение размера chunks сохраняется.
- `DEV_PORT=5434 PW_REUSE_SERVER=1 npx.cmd playwright test tests/e2e/equipment.spec.ts --workers=2`: 22 passed, 51,8 с. Внутри набора сериализация по прежнему describe использует одного worker.
- Новый сценарий на 1280×900 и 1440×900: загрузка before → наведение → выбор типа для установки → подсказка о «Выборе» → клавиатурная активация «Выбора» без движения мыши → обновлённая подсказка → клик по предмету → видимые свойства с правильным именем → экспорт. Сохранённый документ целиком совпадает с исходным: лишнего объекта и скрытой правки нет.
