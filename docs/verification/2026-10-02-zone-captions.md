## Результат

Название зоны ищет место в двух направлениях, с учётом размеров текста, бирок и самостоятельных значков оборудования. Проверяется вложение полного прямоугольника подписи в полигон, в том числе вогнутый. Поиск ограничен 24×24 кандидатами у сетки и граней препятствий; из свободных выбирается ближайший к центру. Если места не найдено, сохраняется наименее перекрытое имя; гарантии для произвольного тесного плана нет.

Общий расчёт domain/zone-caption-layout.ts используется ZoneNameLayer и InformationLayer, поэтому показатели слоя обходят новое положение названия. Чистая логика object-label перенесена в domain с совместимым re-export старого пути. Для скрытых зон информационный слой сохраняет прежний fallback. Расчёт препятствий консервативно учитывает значки даже при отключении иконографики.

## Ограничения

Размер текста предварительный; неизвестные шрифты и длинные имена могут выйти за зарезервированное место, но текст не обрезается фиксированной высотой. Слишком маленькие/заставленные зоны сохраняют fallback с возможным наложением. Совпадение расположения имён зон с SVG/PNG-экспортом не заявляется: экспорт пока использует прежний способ. Положение зон в JSON не меняется.

UI skills из CLAUDE недоступны, выполнен fallback: браузерные сценарии, снимки, реальная проверка строк и геометрии, independent review. Полный accessibility audit, ручная приёмка другой машины и полный browser suite не заявляются; общий прогон редактора остаётся перед выпуском. Main и публичный сервис этим пакетом пока не обновлены.
