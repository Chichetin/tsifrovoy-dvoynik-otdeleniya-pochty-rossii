# Проход operator: три роли на `main` `132a6b3` (20.09.2026, ~12:15)

Субагент `operator` прошёл приложение в браузере (бандловый Chromium 1700×1000,
локальный dev-сервер на порту 5423, ассистент без запросов к LLM) в трёх ролях из
брифа организаторов, с упором на то, что влилось утром: привязка объектов при

видимость слоёв вне «несохранённых правок» (D-207). Всё — на `demo/before.json`
(53 объекта, 8 зон, 9 стен). Скриншоты — `docs/verification/operator-2026-09-20/`.
Числа ниже сняты из карточки свойств и из сохранённого файла, а не на глаз.

Кнопка «Вписать» в правом нижнем углу; после «Вписать» угол плана (15; 0) лежит в 200 px от неё, план под кнопку не попадает. Перехват кликов при ручном зуме не проверял.

## Что работает (не потерять на защите)

- **Привязка к соседу**: стеллаж, брошенный рядом со стеллажом товаров (`eq_36`), встал грань в грань (X 14,1 при правой грани соседа 13,5) и по верхней кромке (6,0 = 6,0), пересечений нет — `04-rack-next-to-neighbour.png`. Серия бросков 12,0…12,5: 12,1 и 12,2 остались как есть, 12,3 → 12,4 (грань на узел сетки 13,0), 12,5 — на сетке. То есть «между» объектами поставить можно, залипания нет — тянет только в допуске.
- **Alt** отключает привязку и при переносе, и при рисовании; результат хранится до сантиметра (в файле 14,19 / 3,53; 12,03 / 3,0).
- **Слои и статус (D-207)**: после открытия — «сохранено»; включил «Тепловая нагрузка зон» и «Очередь по зонам» — по-прежнему «сохранено»; повторное «Открыть» не спрашивает про потерю правок (диалогов 0); сдвинул объект — «есть несохранённые правки»; «Сохранить» — «сохранено»; видимость слоёв в файле сохраняется (`Тепловая нагрузка зон=true`) и после повторного открытия слой показан. Легенда слоя и в панели, и на холсте, обе с подписью «числа синтетические»; проценты нагрузки правятся в панели по зонам — `11-heat-and-queue.png`.
- **Инвентаризация**: поиск «ИНВ-ДЕМО-041» — одна строка, «Показано 1 из 53», клик по строке открывает карточку `eq_41` и подводит план; «стеллаж» — 6 строк. Удалил `eq_44` клавишей Delete — в перечне 52, подпись «выгрузится весь перечень: строк 52», CSV на 52 строки без `eq_44`, с BOM и `;` (Excel откроет), колонки «Инв. №; Объект; id объекта; Тип; id типа; Зона; id зоны». Таблица зон «в самой зоне / с вложенными» сходится (17/27 у клиентского зала). Панель «Справочник» на месте — `13-inventory-search.png`.
- Площади с пояснением, почему зоны не складываются; правила комплектования подписаны «допущение команды, не норматив Почты», правило про терминал — «материалы организаторов».
