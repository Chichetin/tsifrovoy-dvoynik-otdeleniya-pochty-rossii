# Issue #3 — первый шаг: связанные факты

База `989c53f`, ветка `worktree-3-chat-facts`. Модуль пока **не подключён к серверу**: старый дефект свободного чата остаётся, Issue #3 не закрывается этим пакетом.

Код `007310e`, [MR !305](https://git.codenrock.com/codenrock/khakaton-postcode-challenge-ot-pochtatekha/ii-blanki/tsifrovoy-dvoynik-otdeleniya-pochty-rossii/-/merge_requests/305). Независимое ревью итогового diff: блокирующих замечаний не осталось; 22 целевых теста пройдены reviewer повторно.

`collectAgentFacts` читает именованные поля известных успешных инструментов и факты domain-рекомендаций. Факт содержит метрику, область, ссылки, фазу, значение, единицу. Тип поиска хранится даже при отсутствии вариантов. Ключи прогнозов разделены по рекомендации; область подсчёта правила применяется только к комплектованию. Расстояние до середины bounding box при поиске и сумма перемещений при сравнении имеют разные подписи.

`renderAgentFactSelection` принимает только `{factIds: [...]}`. Числа, подписи метрик, единицы, знак и предмет фразы формирует код. Проза, включая числа словами, лишние поля и неизвестные ключи отвергаются. Допущения и ограничения рекомендации автоматически присоединяются к её выбранным фактам. Вопрос и история не являются доказательством.
