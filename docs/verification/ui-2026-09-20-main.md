## Клавиатура (п.6)

Временным тестом проверено, что порядок Tab по всей шапке слева направо
совпадает с видимым расположением групп: Инструменты (Выбор, Рука, Помещение,
Зона, Перегородка, Проём) → Вид (2D, 3D) → История (Отменить, Вернуть) → Файл
плана (**Новый, Открыть, Картинка, Сохранить**) — лог прогона:

```
QA tab order (whole header): Выбор | Рука | Помещение | Зона | Перегородка |
Проём | 2D | 3D | Отменить | Вернуть | Новый | Открыть | Картинка
```

Внутри группы «Файл плана» порядок кнопок при Tab — ровно `Новый, Открыть,
Картинка, Сохранить`, как в брифе; после Tab у активной кнопки виден контур
фокуса (`outline-style: solid`), что дублирует штатный
`tests/e2e/shell.spec.ts` («фокус с клавиатуры виден кольцом, мышью — нет»).
