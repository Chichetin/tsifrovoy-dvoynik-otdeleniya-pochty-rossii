# Задача #32 — покрытие камерами и слепые пятна

Closes #32. Ветка `worktree-32-camera-coverage`, решения D-306, D-307, D-308, строка
`docs/tz-compliance.md` А10.

## Что сделано

- **Расчёт кодом (D-306).** `cameraCoverage` в `src/domain/advice/camera-coverage.ts`:
  доля площади клиентских зон, которую видит хотя бы одна камера слоя «Камеры и зоны
  обзора». Сетка 0,25 м, квадрат в зоне — если его центр в контуре или на ребре, виден —
  если центр в секторе (`viewSectorTest`/`pointInViewSector` в `domain/geometry`, тот же
  сектор, что рисует слой: угол и дальность из атрибутов камеры, пустые — умолчания слоя,
  направление — поворот). Результат: % и м² по каждой клиентской зоне, итог без двойного
  счёта вложенных зон, слепые пятна полосами по строкам сетки.
- **Какая зона клиентская — без правки справочника.** Атрибут зоны `publicAccess`, иначе
  умолчание этого атрибута у типа зоны (`zt_client` — да, `zt_service` — нет), иначе ответ
  родительской зоны. На демо: зал `z_client` и вложенные вход, ожидание, очередь.
- **Отрисовка (D-307).** При включённом слое слепые пятна клиентских зон заштрихованы на
  холсте (одна фигура Konva `camera-blind`), в легенде холста — «Слепые пятна клиентских
  зон · видно N %», в панели слоя — таблица «Покрытие клиентских зон камерами» по зонам и
  итог; имя зоны — кнопка выбора. Пометок условности нет (D-281).
- **Ассистент (D-308).** «Куда поставить камеру, чтобы закрыть слепое пятно» — сценарий
  `place` в существующих контрактах: для типа слоя-сектора (`ot_camera`) вариант выбирается
  по покрытию (самое большое связное пятно, точки через 0,5 м, повороты через 15°), до трёх
  вариантов не ближе 1 м, каждый проходит `validatePlan`. `refs` — зоны пятна и камеры,
  которые сейчас видят клиентские зоны. Эффект «было → стало» в % пересчитывает код из плана
  и кандидата: в допущениях рекомендации, в фактах свободного чата (`coverage.percent`,
  было/стало/изменение в п. п., привязаны к варианту; `plan_overview` отдаёт долю по
  каждой клиентской зоне) и в ответе без LLM. Вопросы «слепые пятна / покрытие / камера»
  роутер без модели отправляет в этот расчёт и предлагает включить слой камер.
- Допущение расчёта (сектор по углу и дальности, стены и мебель не перекрывают, видео не
  подключается) — в `assumptions` рекомендации и README `src/domain/advice`, не в UI слоя.

Числа демо-плана `demo/before.json` (закреплены тестами): видно 18,75 из 63 м² клиентских
зон — **29,8 %**; ожидание 42,3 %, очередь и вход 0 %. Лучший вариант камеры — центр
[8,5; 0,5] м, поворот 315° (угол входной группы, взгляд в зал): **29,8 → 72,1 %
(+42,3 п. п.)**. Камера `eq_25` «Камера зала (вход)» в демо смотрит на северную стену
(поворот 0°, взгляд по +Y) и видит только полосу у стены — поэтому покрытие зала низкое.

## UI/UX skill gate — fallback

Инструмента Skill в сессии builder нет: `ui-ux-pro-max`, `frontend-design`,
`playwright-interactive`, `webapp-testing`, `playwright` (как скилл), `accessibility-scan`,

- **Бриф.** Задача: показать руководителю отделения, какую часть клиентского зала не видит
  ни одна камера, и сколько это в процентах. Состояния: слой выключен — ничего; включён,
  клиентских зон нет — строка «Клиентских зон на плане нет — покрытие считать не по чему»;
  всё видно — штриховки нет, в легенде «видно 100 %»; есть пятна — штриховка и таблица.
  Иерархия: на холсте пятно (область) → легенда (итог); в панели легенда слоя → штриховой
  образец → таблица зон → итог жирным. Цвет: штриховка `rgba(201,42,42,0.6)` 1 px через
  9 px и заливка 6 % — отличается от фиолетовых секторов и пастельных зон, подписи под ней
  читаются; образец в легенде — тот же красный `#C92A2A`. Viewport 1440×900.
- **Детерминированный e2e:** `tests/e2e/layers.spec.ts` — открыть демо → включить слой →

## Контракт

## Замечено, не в зоне задачи

- Любая правка документа, включая «Включить слой» из ответа ассистента, делает кнопки
  ответа устаревшими: если сначала нажать «Включить слой», «Применить» станет недоступна.
  e2e нажимает «Применить» первым. Порядок действий или то, что показ слоя меняет ревизию, —
  вопрос `src/app` / `features/assistant` (поток 2).
