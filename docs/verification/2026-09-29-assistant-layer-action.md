# Приёмка действия «Включить слой» в ответе ассистента — Issue #47

В ответе, который содержит предложение варианта и `show-layer`, старый код после «Включить слой» отключал «Применить»: новый браузерный тест упал с `Expected: enabled; Received: disabled`. Это воспроизведение зарегистрированной ошибки без внешнего LLM: ответ API в тесте содержит рассчитанный кодом вариант и действие для скрытого слоя.

После D-317:

- `DEV_PORT=5439 PW_REUSE_SERVER=1 npx playwright test tests/e2e/assistant-insert.spec.ts tests/e2e/assistant.spec.ts tests/e2e/layers.spec.ts --workers=1` — 20/20. Сценарий нажимает «Включить слой „Камеры и зоны обзора“», убеждается, что «Применить» доступна, вставляет вариант, удаляет его, получает новый ответ и проверяет, что прежний устарел. Экспорт JSON содержит включённый слой и вставленный объект.
- Unit `plan-store.test.ts`: переключение видимости и undo/redo меняют обычную ревизию и видимость документа, но сохраняют `contentRevision`; правка объекта, её undo и замена документа повышают `contentRevision`.
- Полный `npm test -- --run` — 1625 passed, 1 skipped; `npm run typecheck`, `npm run lint`, `npm run build` — успешно. Предупреждение о крупных чанках сборки не связано с задачей.
- [Снимок](2026-09-29-assistant-layer-action.png) после включения слоя осмотрен: слой и покрытие видны слева и на плане, кнопка «Применить» доступна справа. Снимок сделан при 1440×900.
