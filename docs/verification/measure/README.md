## Ширина знака подписи

`WALL_LABEL_CHAR_PX` не подобрана на глаз: она измерена в Chromium для шрифта,
которым Konva рисует текст по умолчанию (11 px Arial). Результат —
`char-width.json`, получен так:

```js
const context = document.createElement('canvas').getContext('2d');
context.font = '11px Arial';
context.measureText('12,50 м').width / '12,50 м'.length;
```

Измерено 5,34 px на знак для «4,20 м» и 5,45 px для «12,50 м». В коде взято 6,0 —
с запасом на подстановку шрифта там, где Arial нет. Запас направлен в сторону
«скрыть подпись у самой короткой стены», а не «выпустить её за концы стены»:
подпись длиннее своей стены и была тем, ради чего порог заводился.

## Известные ограничения

- Подпись длины не расходится с другими подписями на плане: рядом с короткой
  перегородкой она может лечь на имя зоны или на подпись объекта. Правило ухода
  от препятствий, как у имён зон (D-216), для неё не делалось.
- Внутренние перегородки подписываются с той стороны, которая дальше от середины
  помещения; для перегородки, проходящей через середину, сторона выбирается
  «вверх экрана». Это стабильно, но не всегда там, где свободнее.
- Слой линейки — десятый Konva-слой сцены; Konva предупреждает о числе слоёв
  начиная с шестого. Слой пуст и ничего не слушает, пока не меряют, а отдельным
  он сделан по D-177: монтировать и размонтировать слой дороже, чем держать
  пустой.
- Маркер цели привязки остаётся на холсте после законченного измерения, пока
  курсор над холстом, — так же, как при рисовании (D-224).
