# #52 — имя и назначение комнаты до создания

Добавлены поля «Название комнаты» и «Назначение комнаты». Тип берётся из справочника плана; значения атрибутов — `defaultAttributes(type)`. Пустое имя и удалённый тип не создают комнату другого назначения. Возврат угла сохраняет ввод, новый документ сбрасывает поля. После успешного создания предлагается имя следующей комнаты. Формат и контракты не менялись: тот же batch стен и зоны.
