## Поведение

В панели «Ассистент», сценарий «Эффект изменений», действие «Сравнить с файлом…» читает отдельную исходную версию. Таблица показывает площадь помещения/занятую/свободную, количество предметов, ошибки и предупреждения, разницу. Имена добавленного/удалённого/перемещённого объекта взяты из нужной версии; ID доступны через details. Список также включает помещение и слои, но не стены/проёмы/справочник: ограничение раскрыто рядом.

Источник, замена и сброс видны пользователю. Ошибочный файл сохраняет предыдущую базу. Правка текущего плана пересчитывает таблицу; загрузка базы не меняет текущий документ, dirty, undo или save baseline. Новый/повторно открытый документ очищает источник и инвалидирует незавершённое чтение. Выбор/сброс базы инвалидирует старый ответ сценария; запрос «Спросить» использует выбранную базу, блокируется при чтении/разных ID планов. Чат выше сохраняет прежнюю точку отсчёта открытия/сохранения; внешний файл относится к сценарному сравнению, не подменяет историю чата.

Реальный комплект demo: 114,73 → 113,93 м² свободно, 53 → 53 предмета, 1 → 0 ошибок, 2 → 0 предупреждений; eq_54 добавлен, eq_8 удалён, eq_1 перемещён. Для разных ID сопоставление не установлено: только независимые показатели с явным предупреждением, без ложных переносов.
