# Перпендикулярные Т-стыки и демо, #52 — 02.10.2026

Ветвь Т-стыка теперь заканчивается на грани проходящей стены: поддержаны примыкание к середине одного отрезка и пара противоположных одинаковых отрезков. Внешние углы по-прежнему стыкуются диагональю. Общий профиль используется в 2D, 3D, SVG/PNG, привязках, поиске места и физике. JSON и координаты стен не изменены.

У соседнего проёма сохраняется прежний торец: пустота двери не заменяет удалённый материал ветви. Все потребители передают openings; 3D использует весь список, а не только проёмы своей стены. Это консервативно для любой высоты проёма. Разная высота, слишком короткие/косые/неоднозначные многолучевые стыки остаются на fallback. Пустые остатки перед дверью исключаются из wallObstacles.
