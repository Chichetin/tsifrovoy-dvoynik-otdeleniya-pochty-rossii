# Q02 — повтор на кандидате после доработок редактора

Прогон 18.09.2026 на ветке E02 `a627c8d` (продуктовый код — `origin/main`
`17ad4dc`). Это кандидат **до** слияния E01, не окончательный commit сдачи.
Среда и генератор те же, что в [первом замере](performance.md): Windows
10.0.26200, Chrome 153.0.8010.12, Ryzen AI 9 365, 24,8 ГБ RAM, seed
`20260918`, пять независимых контекстов на каждый объём. Сырые значения —
в [JSON](performance-rc-raw.json).

`p50` — третье, `p95` — пятое отсортированное значение из пяти. Для запуска
отдельно поднят Vite **из этого worktree** на порту 5191, затем выполнено
`DEV_PORT=5191 PW_REUSE_SERVER=1 npm run test:perf -- tests/perf/editor.spec.ts`.
Результат Playwright — **3/3 passed (1,9 мин)**. Эти времена включают ожидания
Playwright, но не запуск браузера и не загрузку начальной страницы. Планы
синтетические. На 1000 объектах операции открытия заметно медленнее, так что
показывать такой план как «мгновенный» нельзя. Повторить после фиксации
окончательного `origin/main` и публичного сервиса; этот файл остаётся честным
срезом промежуточного кандидата.
