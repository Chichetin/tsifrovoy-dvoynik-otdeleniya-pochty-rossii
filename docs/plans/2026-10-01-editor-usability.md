## Четвёртый шаг — отмена ошибочного угла (02.10)

Бриф: человек ошибся при рисовании, нажал «Отменить» и должен исправлять текущий рисунок, сохраняя уже созданные стены. Внутренняя комната получает видимую кнопку возврата последнего угла; после возврата второго угла первый сохраняется. Верхняя кнопка и Ctrl+Z убирают угол активного рисунка, без рисунка работают с историей документа. Удержание сочетания не переходит из рисунка к старым правкам. Возврат документной правки на время рисунка отключён; история отменённых углов пока не восстанавливается через Ctrl+Y.

Ручки прежнего выделения скрываются при рисовании: они перехватывали клик общей вершины и портили новую комнату. Прямоугольник показывает два реальных угла, а не четыре угла полигона и неверную подсказку «замкнуть». Контракт JSON/UI не изменяется; дополнительные props локальные. UI gate skills недоступны — fallback по прежнему протоколу. Четвёртый снимок пакета `docs/verification/2026-10-01-room-draft-undo.png` осмотрен.

Проверки: новая регрессия сначала красная (removeLast не существовал), после 2/2 unit контроллера. До последней подписи 3/3 internal-room+room-confirmation; финальный сценарий отмены 1/1 (5,2 с) с явной проверкой доступности создания второй комнаты, сохранения прежних зон/стен, повторного Ctrl+Z, отмены внешнего контура, документного undo/redo. typecheck/lint/build exit 0. Два запуска с автоматически поднятым Vite зависли при завершении после выполнения сценариев и остановлены (exit 1), не объявляются зелёными. Старые PNG, перезаписанные тестами, восстановлены; новый снимок относится только к этой правке. Свежий read-only review не обнаружил оставшихся конкретных дефектов, включая два маркера.
