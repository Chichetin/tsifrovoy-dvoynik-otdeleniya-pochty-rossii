## Идеи UX и небольшие фичи (28.09, второй заход)

Каждая — не больше дня и видна на защите за 10–20 секунд. Отбор — по роли, для которой
идея делается, и по критерию оценки. «Контракт» — нужен отдельный MR через поток 1
(новое поле в файле). Наличие проверено по `git grep`: минимап, выравнивания,
блокировки, покрытия камерами и командной палитры в `src/` нет.

### Мелкая полировка (по XS, можно брать в промежутках)

- Удаление показывает «Объект удалён · Отменить» на 7 секунд — дешёвая страховка от случайной потери.
- Пустые состояния с действием: пустая инвентаризация → «Добавьте объект из библиотеки слева», пустой план → две большие кнопки «Нарисовать помещение» / «Открыть демо».
- Строка инвентаризации при наведении подсвечивает объект на плане, при клике — ведёт к нему (сверить с `focus.ts`, возможно уже частично есть).
- Двойной клик по названию зоны на плане — переименовать на месте.

**Что брать первым** (моя оценка, подтвердить командой): S2-24, S2-29, S2-32, S2-36, S2-39.
Каждая закрывает свой критерий и хорошо смотрится на пятиминутной защите: редактор
как инструмент, «новый слой данными», число, которое посчитал код и видно на плане, и
документ, который руководитель уносит с собой. Все UI-идеи проходят skill gate из
`CLAUDE.md`, S2-31 — отдельный MR контракта через поток 1.
