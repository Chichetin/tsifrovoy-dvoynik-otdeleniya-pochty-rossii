У браузерного теста уже есть запрет overflow и минимальный свободный запас 20 px — это критерий. Фиксировать измеренный запас для всех шести viewport, отдельные скриншоты 1280/1460 и keyboard доступ к «Демо». Открыть демо → изменить → выгрузить → открыть заново; проверить open-demo e2e.
