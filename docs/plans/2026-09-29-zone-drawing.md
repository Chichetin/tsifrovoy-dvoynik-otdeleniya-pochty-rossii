# Issue #43 — понятное рисование зоны

Максим / Codex, `worktree-43-zone-drawing`, база `3fd4e61`. Приоритет — прямое замечание пользователя и снимок красного самопересекающегося черновика.

Существующий многоугольник сохраняем: последовательные углы по контуру, первая точка замыкает; Enter/двойной клик и Esc остаются. На холсте видны пронумерованные углы, выделенное начало и следующее ребро под мышью. В левой панели компактная карточка: «Нажмите первый угол», затем число углов и действия «Завершить зону», «Убрать последний угол», «Отменить». До трёх углов завершение недоступно. Самопересечение объясняется рядом и исправляется возвратом шага или отменой; ошибочная зона не сохраняется.

Расширение реализации контроллера — локальный тип в feature, совместимый с прежним ToolController; общие contracts и JSON не меняем. Отказ store не должен уничтожать черновик. Возврат шага/отмена не создают команду, валидное завершение — одна команда, одно undo. Видимые controls не должны перекрывать холст и верхнюю полосу ошибки; доступные кнопки и клавиатура. При смене инструмента/плана черновик и подсказки сбрасываются.

Проверки: controller unit (слишком мало точек, самопересечение, возврат, отказ store, единичная команда); browser на 1280×800/1440×900 (рисование по кнопкам, исправление, undo, сохранение/повторное открытие); старые plan-tools сценарии, unit/typecheck/lint/build, снимки с просмотром и независимое ревью. Требуемые UI-скиллы отсутствуют в доступном каталоге; fallback Playwright/клавиатура/снимки/проверка границ. Полный UI gate не заявляется без scan/inspect/zoom.
