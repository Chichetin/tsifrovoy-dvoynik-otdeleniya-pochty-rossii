# Issue #5 — исходный файл для сравнения

Максим / Codex, `worktree-5-compare-file`, база `3fd4e61`.

При открытом изменённом плане пользователь выбирает отдельный исходный JSON через «Сравнить с файлом…» в сценарии «Эффект изменений». Файл читается обычным codec. База сравнения хранится отдельно от редактируемого документа и baseline сохранения; не меняет dirty, undo, ID и формат. Исходный файл назван в панели, доступна замена и сброс к моменту открытия/сохранения. Смена текущего документа очищает внешнюю базу; текущие правки автоматически пересчитывают таблицу.

Результат: детерминированная таблица площади, числа предметов, ошибок и предупреждений; список изменений с именами из соответствующей версии и доступными ID. Расчёт использует measurePlan, validatePlan и diffPlans. Для разных ID планов только независимые сводные показатели и явное предупреждение: сопоставление объектов не выполняется, совпавшие локальные ID не означают один предмет. Внешняя база не должна незаметно попасть в старый запрос/ответ ассистента; смена базы отменяет/инвалидирует результат сравнения.

Пакеты: 1) чистый domain-отчёт и проверки реальных demo, без UI; 2) контроллер чтения/замены внешней базы с защитой от поздних ответов и ошибок; 3) UI в текущей панели + композиция App, отдельное ревью, полный сквозной браузерный сценарий. Каждый проверенный пакет коммитится и отправляется отдельно. Первый пакет не закрывает Issue.

Приёмка: before→after совпадает с demo/effect.md (114,73→113,93 м², 53→53, ошибки 1→0, предупреждения 2→0, eq_54 добавлен, eq_8 удалён, eq_1 перенесён); переименование/редактирование пересчитываются; посторонний/повреждённый файл не выдумывает соответствие и не затирает план/предыдущую базу; экспорт и undo неизменны. UI 1280×800 и 1440×900, клавиатура, снимки и просмотр. Требуемые UI-скиллы отсутствуют: fallback из действующей спецификации, полный skill gate не заявляется.
