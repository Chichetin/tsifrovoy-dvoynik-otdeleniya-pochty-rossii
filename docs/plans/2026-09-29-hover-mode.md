# Issue #42 — подсказка предмета учитывает инструмент

Максим / Codex, `worktree-42-hover-mode`, база `1dc3f42`.

Проблема пользователя: карточка наведения предлагает нажать на предмет, хотя выбранный инструмент установки по этому нажатию создаёт другой предмет. Подсказка должна назвать сам предмет на холсте и левую панель «Свойства», а при установке/рисовании сначала направить к «Выбору» в шапке.

Сохраняем размеры, стиль и отсутствие перехвата кликов карточкой. Обновляем подсказку при смене инструмента с неподвижной мышью, пересчитываем высоту и удерживаем карточку в холсте. Поведение выбора, установки, перемещения и формат документа не меняем. Проверка: unit режимов, реальный hover→смена инструмента→клик→свойства, неизменность числа предметов, 1280/1440, снимки, equipment e2e, typecheck/lint/build.

Указанные в CLAUDE.md UI-скиллы отсутствуют в доступном каталоге. Применяем документированный fallback: Playwright, клавиатура, проверка текста/границ карточки и просмотр снимков. Полный UI skill gate не заявляем.
