# #28 — слой «Состояние оборудования»

Роль: сотрудник эксплуатации быстро видит на готовом 2D-плане, какие устройства требуют ремонта или списания, и меняет состояние без поиска технического ID. На финальном питче это короткий показ информационного слоя поверх того же структурированного плана.

UI-бриф: в «Слоях» новая карточка с переключателем видимости, четырьмя цветами и счётчиками. Каждый цвет — клавиатурная кнопка-фильтр (`aria-pressed`); таблица показывает только выбранное состояние, названия объектов ведут к выделению, селект меняет атрибут. Серый означает «не указано», а не «исправно». Цвет корпуса на холсте и в SVG/PNG совпадает. Палитра — приглушённые насыщенные цвета; иконки и подписи объектов остаются поверх. Целевые окна 1280×800 и 1440×900, на маленьком экране список прокручивается. Проверка: демо → включить слой → увидеть три статуса → исправить один → сохранить JSON → открыть снова; также пустой план и добавление объекта.

Контракт: новый вид `object-color` со строковым ключом, значением по умолчанию и перечнем `value`/`label`/`color`. Слой не содержит объекты и не меняет геометрию. Если значение отсутствует или неизвестно, показывается явный вариант «Не указано». При нескольких видимых цветовых слоях последний по порядку определяет цвет; обычный цвет типа возвращается при скрытии. Второй слой того же вида должен добавляться записью каталога, без нового кода. Кодек записывает все поля представления и восстанавливает их.
