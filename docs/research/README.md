# Независимое исследование

`deep-research-brief.md` — набор из 13 самостоятельных промптов R01–R13 и отдельного
финального аудита R14. Каждый промпт рассчитан на отдельный чат ChatGPT; рядом с ним
указаны точные файлы для прикрепления. R01–R13 не требуют текущий код и результаты
других чатов, чтобы сохранить независимость мнений. R14 запускается последним и уже
аудирует текущие документы вместе с полученными отчётами.

Исторические материалы текущего исследования R01:

- [Проверка полученного анализа и ограничения](deep-research-report.md) — начать здесь.
- [Исходный PASS-2 от 17.09.2026](pass2-comparison-2026-09-17.md) — сохранён без изменений; утверждения автора не равны результатам нашего запуска.
- [Набор копируемых промптов](deep-research-brief.md) — актуальная точка запуска новых независимых исследований.

Код приложения и контрактов промптами не меняется; выводы исследований нужно
сохранять отдельно и принимать только после сверки с первичными источниками и
воспроизводимыми проверками.
