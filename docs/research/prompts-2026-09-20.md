# Промпт, актуальный на 20.09.2026

`deep-research-brief.md` написан 19.09, когда решения ещё принимались. К 20.09 бо́льшая
часть его вопросов закрыта не мнением, а прогонами: формат и справочники, проверка
ответа модели, 3D, замеры на 100/500/1000 объектов, тесты и декомпозиция потоков.
Ответы на R04–R11 придут в готовый продукт и смогут только предложить переделать
проверенное за сутки до сдачи.

Открытым остаётся один вопрос — **где поднять публичный адрес сервиса**: в README и
`docs/submission.md` он до сих пор `TBD`, а без него жюри не откроет сервис. Промпт
ниже самодостаточен: копируется целиком в отдельный чат, весь нужный контекст внутри,
шапку добавлять не надо. Прикладывать файлы не обязательно, `docs/deployment.md` только
уточняет детали.

Решением команды 20.09 сняты ещё три темы из прежнего набора: показ и презентацию
делаем сами, запасной провайдер LLM не нужен (работаем на Yandex Cloud AI Studio),
финальный аудит перед сдачей проводит свой субагент `jury`, который видит весь
репозиторий, а не вложения.

Результат складывать в `docs/research/results/`. Выводы принимаются после сверки с
первичными источниками, а не по числу совпавших мнений — правило из
[README исследования](README.md).

## Площадка для публичного адреса

```text
Ты — независимый инженер по развёртыванию. Нужен ответ для решения, которое
принимается сегодня, а не обзор рынка. Сегодня 20.09.2026; адрес нужен к 22.09.2026,
23:59 МСК и должен работать как минимум до 30.09.2026 (дата проверки жюри неизвестна).

Задача: поднять публичный адрес для небольшого веб-сервиса и держать его до конца
сентября. Сервис — один Docker-контейнер на базе node:22-alpine, многоступенчатая
сборка, внутри один процесс Node, который отдаёт и статику одностраничного
приложения, и HTTP API. Запускается командой docker compose up --build -d, слушает
порт 8080 (меняется переменной PORT). Базы данных нет, диск между перезапусками не
нужен: пользователь хранит данные в файлах у себя. Есть проверка живости
GET /api/health. Один секрет — API-ключ языковой модели — задаётся переменной
окружения и не должен попадать ни в образ, ни в репозиторий. Сервису нужны исходящие
HTTPS-запросы к API языковой модели (Yandex Cloud AI Studio); ответ модели приходит за
20–60 секунд, поэтому обратный прокси или балансировщик площадки не должен рвать
соединение раньше 60 секунд.

Требования к площадке:
- публичный HTTPS-адрес, открывается в браузере без регистрации, логина и VPN;
  выданный поддомен подходит, свой домен не нужен;
- оплата из России картой российского банка либо тариф, на котором оплата не нужна;
- развёртывание человеком за час без прежнего опыта именно с этой площадкой;
- переменные окружения задаются без пересборки образа;
- сервис отвечает сразу, когда его откроют: если тариф усыпляет контейнер, назови
  время холодного старта;
- исходящие запросы к внешним API не блокируются — отдельно проверь, доступен ли
  API Yandex Cloud AI Studio с IP-адресов этой площадки и её региона.

Сравни 5–7 реальных вариантов: российские облака и хостинги, зарубежные PaaS с
поддержкой Docker, обычный VPS с установкой Docker руками. Для каждого дай тариф и
цену в рублях в месяц с датой проверки, способ оплаты из РФ, поддержку Docker и
compose, способ задать секреты, наличие HTTPS из коробки, лимиты (трафик, память,
время работы, срок действия бесплатного тарифа), поведение при превышении лимита,
холодный старт и то, что произойдёт с адресом через месяц.

Правила: цену, возможность оплаты из РФ и лимиты подтверждай ссылкой на официальную
страницу с датой проверки; не пересказывай статьи и подборки; то, что нельзя узнать
без регистрации, помечай UNKNOWN. Не предлагай Kubernetes, CI/CD, terraform,
мониторинг и балансировку — нужен один контейнер на одном хосте.

Формат ответа:
1. Таблица: площадка → цена → оплата из РФ → Docker/compose → секреты → HTTPS →
   лимиты → холодный старт → источник с датой.
2. Рекомендация: основной вариант и запасной, с критерием переключения.
3. Пошаговая инструкция для основного варианта — от регистрации до открытого
   HTTPS-адреса, с командами.
4. Что проверить сразу после подъёма, включая запрос к API модели с ответом дольше
   30 секунд и открытие адреса с чужой машины.
5. Риски: что может отвалиться за два дня и что тогда делать.
6. Источники с датами проверки, UNKNOWN и допущения.
```
