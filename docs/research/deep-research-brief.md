# Набор независимых промптов для исследования

Этот файл предназначен для ручного запуска нескольких независимых исследовательских
сессий в ChatGPT. Каждый блок ниже можно копировать целиком в отдельный чат. Не
прикладывайте к независимому исследованию ответы других чатов: цель — получить
несколько самостоятельных мнений, а не заставить все сессии согласиться с одним
первым выводом.

## Как пользоваться

1. Создайте отдельный чат для каждого промпта.
2. Прикрепите только файлы, перечисленные непосредственно перед его блоком.
3. Включите веб-поиск, если он доступен. Не просите чат менять репозиторий или писать
   код: результатом должен быть исследовательский отчёт с решениями и источниками.
4. Сохраните каждый ответ отдельно с номером промпта. Не редактируйте вывод до
   сравнения результатов; исправления и общий план делайте отдельным этапом.
5. Для актуальных API, цен, версий и доступности перепроверяйте дату и регион
   (Россия, если не указано иное). Текущая дата проекта — 19.09.2026, сдача —
   22.09.2026, 23:59 МСК; если фактическая дата чата другая, укажите обе.

## Общий контекст, который повторяется в каждом промпте

Проект — веб-сервис «Цифровой двойник отделения Почты России» для внутренних ролей:
руководителя отделения, проектировщика перепланировки, специалиста по инвентаризации
и эксплуатации. Основной инструмент — 2D-редактор синтетического плана помещения:
помещение, функциональные зоны, информационные слои, оборудование, координаты,
размеры, поворот, уникальные ID и атрибуты. Нужны сохранение/загрузка, инвентаризация,
проверки корректности, объяснимый ассистент по перепланировке и условное 3D.

Вес критериев конкурса: 2D-редактор и масштабируемость — 30%; модель, инвентаризация
и расширяемость справочников — 20%; рекомендации ассистента — 20%; загрузка,
проверки, сохранение и повторное открытие — 15%; воспроизводимость и README — 10%;
3D — 5%. Обязательные семейства объектов: рабочие места, кассовые окна, терминалы,
принтеры, стеллажи, места ожидания, камеры и инженерное оборудование. Новый тип
объекта, зоны, слоя или атрибута должен добавляться данными, без переписывания кода.

Ассистент должен уметь искать место для рабочего места/окна/стеллажа, находить
недостающее или лишнее оборудование и показывать влияние изменения на свободную
площадь и инвентаризацию. Числа считает детерминированный код; модель формулирует
объяснение и ссылается на конкретные ID и факты. Ответ модели проверяется до показа;
при недоступном API работает понятный fallback без LLM. Для продукта разрешены только
Qwen, DeepSeek, GigaChat или YandexGPT по API; секреты должны оставаться вне git.

Используются только синтетические данные. Нельзя предлагать OCR PDF/DWG/сканов,
реальные планы БТИ, видеонаблюдение, видеоанализ очередей, 1С, мобильную версию,
фотореалистичный 3D или автоматическую перестановку вместо пользователя.

Общие правила для исследователя:

- не соглашайся с предпосылками автоматически и не ссылайся на другие ответы;
- используй веб-поиск для актуальных и технических утверждений;
- для важных утверждений приводи первичный источник: официальную документацию,
  upstream-репозиторий, лицензию, стандарт или научную статью;
- разделяй «доказано источником», «вывод» и «что нужно проверить прототипом»;
- не выдумывай цены, доступность из РФ, benchmark, отзывы жюри, нормативы или
  результаты запуска;
- неизвестное помечай как `UNKNOWN`, а рискованное предположение — как `HYPOTHESIS`;
- все рекомендации связывай с одним или несколькими критериями конкурса;
- ответ пиши по-русски, ссылки давай на конкретные страницы, источники датируй.

## R08. Упрощённое 3D и согласованность с 2D

**Прикрепить:** `task.md`, `example_plan.json`.

```text
Ты — независимый исследователь lightweight 3D-визуализации инженерных планов.
```
